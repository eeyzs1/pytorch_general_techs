## 二、数据清洗六类问题（核心框架）

真实业务数据 80% 的时间花在清洗上。无论数据来自 DB、API、日志还是聊天导出，脏数据问题都可以归到下面六类。掌握这套框架，拿到任何一份脏数据都能快速拆解。

### 2.1 六类问题总览

| 序号 | 问题类型 | 本质 | 典型示例 | 本课时节 |
|------|---------|------|---------|---------|
| 1 | 缺失 | 字段值为空或无效 | 手机号为 NULL、年龄为空字符串 | 第三节 |
| 2 | 异常 | 数值远离正常分布 | 订单金额 = -99 元、年龄 = 200 | 第四节 |
| 3 | 重复 | 同一实体被记录多次 | 同一笔订单出现两行、同一用户重复注册 | 第五节 |
| 4 | 格式不统一 | 同一语义有多种表达 | "2024-01-01"/"2024/1/1"/"20240101" | 第六节 |
| 5 | 逻辑矛盾 | 字段间或与业务规则冲突 | 结束时间 < 开始时间、未成年却办了信用卡 | 第七节 |
| 6 | 编码 | 字符编码不一致导致乱码 | UTF-8 文件混入 GBK 行、CSV 带 BOM | 第八节 |

## 三、缺失值处理

### 3.1 识别缺失

缺失不只是 `NULL`。真实数据里，以下都应识别为缺失：

| 缺失形态 | 示例 | 识别方法 |
|---------|------|---------|
| 数据库 NULL | `NULL` / `None` / `NaN` | `isnull()` / `IS NULL` |
| 空字符串 | `""` / `"   "` | `str.strip() == ""` |
| 占位符 | `"N/A"` / `"null"` / `"-"` / `"未知"` | 维护占位符字典，统一映射为 NULL |
| 非法默认值 | 年龄 = 0、金额 = 0、日期 = 1970-01-01 | 结合业务规则识别 |

> **关键**：先把这些"伪非空"统一转成真正的 NULL，否则后续统计空值率会严重低估。

### 3.2 处理策略：删除 vs 填充 vs 插值

**先理解缺失机制**（决定策略的前提）：

| 机制 | 全称 | 含义 | 例 |
|------|------|------|----|
| MCAR | 完全随机缺失 | 缺失与任何变量无关 | 采集脚本随机丢包 |
| MAR  | 有条件随机缺失 | 缺失依赖其他已观测变量 | 年龄越大越不愿填手机号 |
| MNAR | 非随机缺失 | 缺失依赖自身未观测值 | 高收入者不愿填收入 |

**三种处理策略**：

```
删除（Drop）
  ├── 适用：缺失比例 < 5%、MCAR、非关键字段
  ├── 优点：简单、不引入偏差（仅 MCAR 时）
  └── 缺点：丢信息；MAR/MNAR 下会引入偏差
  ├── pandas:  df.dropna()           df.dropna(subset=['phone'])
  └── Spark:   df.na.drop()          df.na.drop(subset=['phone'])

填充（Fill）
  ├── 适用：缺失比例 5%-40%、字段重要不能删
  ├── 数值列：均值 / 中位数 / 众数 / 固定值（如 0）
  ├── 类别列：众数 / 新增类别 "Unknown"
  ├── 时间列：前向填充 ffill / 后向填充 bfill
  ├── 优点：保留样本量
  └── 缺点：可能扭曲分布（尤其均值填充会压低方差）
  ├── pandas:  df.fillna({'age': df['age'].mean()})
  │            df['col'].fillna(method='ffill')
  └── Spark:   df.na.fill({'age': 30})

插值（Interpolate）
  ├── 适用：时间序列、有序数据
  ├── 方法：线性插值 / 三次样条 / 时间插值
  ├── 优点：保留序列趋势
  └── 缺点：仅适合有序数据
  └── pandas:  df['col'].interpolate(method='linear')
               df['col'].interpolate(method='time')
```

### 3.3 代码示例：pandas 与 Spark 两种实现

**pandas 实现**：

```python
import pandas as pd
import numpy as np

# ========== 1. 构造含缺失的样本 ==========
df = pd.DataFrame({
    "order_id": [1001, 1002, 1003, 1004, 1005],
    "user_id": ["U001", None, "U003", "U004", "U005"],          # 含 NULL
    "phone": ["13800138000", "N/A", "13800138002", "", None],   # 含占位符/空串/NULL
    "age": [25, 30, np.nan, 0, 45],                             # 0 是非法默认值
    "amount": [199.0, 299.0, np.nan, 399.0, 499.0],            # 数值缺失
    "create_time": pd.to_datetime(
        ["2024-01-01", "2024-01-02", None, "2024-01-04", "2024-01-05"]
    ),
})

# ========== 2. 把"伪非空"统一转成真正的 NULL ==========
# 占位符字典：这些值在业务上都算缺失
placeholder = ["N/A", "null", "-", "", "未知"]

def to_real_null(series, placeholders=placeholder):
    """把占位符、空字符串都转成 NaN"""
    if series.dtype == "object":
        # 字符串列：strip 后匹配占位符
        s = series.astype(str).str.strip()
        return series.where(~s.isin(placeholders) & (s != "nan"), np.nan)
    return series

df["phone"] = to_real_null(df["phone"])

# 数值列的非法默认值（age=0）也转成 NaN
df.loc[df["age"] == 0, "age"] = np.nan

# ========== 3. 统计缺失率（决定策略） ==========
missing_rate = df.isnull().mean()
print("各列缺失率：")
print(missing_rate)

# ========== 4. 按策略处理 ==========
# (a) 删除：user_id 是主键，缺失行无法关联，直接删
df = df.dropna(subset=["user_id"])

# (b) 填充-类别列：phone 缺失填 "Unknown"
df["phone"] = df["phone"].fillna("Unknown")

# (c) 填充-数值列：age 用中位数填充（比均值抗异常值）
df["age"] = df["age"].fillna(df["age"].median())

# (d) 插值-时间列：amount 按时间线性插值
df = df.sort_values("create_time")
df["amount"] = df["amount"].interpolate(method="linear")

print("\n清洗后：")
print(df)
```

**Spark 实现**（大数据量场景）：

```python
from pyspark.sql import SparkSession, functions as F, types as T, Window

spark = SparkSession.builder.appName("MissingValueClean").getOrCreate()

df = spark.read.parquet("/warehouse/ods/ods_order_info")

# ========== 1. 占位符统一转 NULL ==========
placeholder_set = ["N/A", "null", "-", "", "未知"]
# 用 when/otherwise 把占位符替换为 NULL
for col_name in ["phone", "user_name"]:
    df = df.withColumn(
        col_name,
        F.when(F.trim(F.col(col_name)).isin(placeholder_set), None)
         .otherwise(F.col(col_name))
    )

# 非法默认值 age=0 转 NULL
df = df.withColumn(
    "age",
    F.when(F.col("age") == 0, None).otherwise(F.col("age"))
)

# ========== 2. 统计缺失率 ==========
total = df.count()
missing_stat = df.select([
    (F.count(F.when(F.col(c).isNull(), c)) / F.lit(total)).alias(c + "_missing_rate")
    for c in df.columns
])
missing_stat.show()

# ========== 3. 按策略处理 ==========
# (a) 删除：主键缺失行
df = df.na.drop(subset=["order_id", "user_id"])

# (b) 填充：用 Spark 聚合算出中位数/众数再填充
# 数值列 age 用中位数近似（用 percentile_approx）
age_median = df.stat.approxQuantile("age", [0.5], 0.01)[0]
df = df.na.fill({"age": float(age_median)})

# 类别列用众数（groupBy 排序取第一）
mode_phone = (df.groupBy("phone").count()
              .orderBy(F.desc("count")).first()["phone"])
df = df.na.fill({"phone": mode_phone})

# (c) 时间序列插值：Spark 没有原生 interpolate，用窗口函数实现线性插值
# 思路：用前一个非空值 forward fill（ffill）
w = Window.orderBy("create_time").rowsBetween(Window.unboundedPreceding, 0)
df = df.withColumn(
    "amount_ffill",
    F.last("amount", ignorenulls=True).over(w)
)
```

## 四、异常值检测

### 4.1 统计方法：IQR、Z-score、3σ

| 方法 | 原理 | 判定阈值 | 适用分布 | 优缺点 |
|------|------|---------|---------|--------|
| IQR | 四分位距，超出 [Q1-1.5IQR, Q3+1.5IQR] 为异常 | 1.5×IQR（极端用 3×IQR） | 任意分布 | 抗异常值，最常用 |
| Z-score | 标准化后，|z| > 3 为异常 | z > 3 | 近似正态 | 受异常值本身影响 |
| 3σ | 正态分布下 99.7% 数据在 μ±3σ 内 | μ±3σ | 正态分布 | 同 Z-score，对偏态分布失效 |

> **选择建议**：业务数据多为长尾/偏态分布，**优先用 IQR**；只有确认近似正态（如身高、考试成绩）才用 3σ。

### 4.2 规则方法：业务规则

由业务方给出硬性边界，最可靠但需人工维护：

```
年龄：       [0, 150]
信用卡年龄：  [18, 100]
订单金额：    (0, 1000000]
商品数量：    [1, 999]
手机号长度：  11 位
身份证号长度：18 位
下单时间：    不能晚于当前时间
```

### 4.3 机器学习方法：孤立森林

**原理**：随机选特征 + 随机选切分点递归划分数据。异常点"稀少且不同"，平均只需更少切分就能被孤立（路径更短）。路径长度越短，越可能是异常。

**适用**：多维数据、无明显分布假设、异常比例未知（一般设 1%-5%）。

```python
from sklearn.ensemble import IsolationForest
import numpy as np

# 构造样本：amount 有少量异常
X = np.array([
    [199], [299], [399], [499], [250], [310], [180], [420],
    [99999],   # 异常：极高
    [-99],     # 异常：负数
    [0],       # 异常：零
]).reshape(-1, 1)

# 训练孤立森林
iso = IsolationForest(
    n_estimators=100,
    contamination=0.15,       # 预估异常比例 15%
    random_state=42
)
labels = iso.fit_predict(X)   # 1=正常, -1=异常

for v, lab in zip(X.ravel(), labels):
    print(f"amount={v:>6}  ->  {'异常' if lab == -1 else '正常'}")
```

### 4.4 代码示例：用 IQR 和孤立森林检测金额异常

```python
import pandas as pd
import numpy as np
from sklearn.ensemble import IsolationForest

# ========== 1. 构造订单金额数据 ==========
np.random.seed(42)
normal = np.random.normal(300, 80, 1000).round(2)   # 正常订单
outliers = np.array([-99, 0, 99999, 50000, -50])    # 人造异常
amount = np.concatenate([normal, outliers])
df = pd.DataFrame({"order_id": range(len(amount)), "amount": amount})

# ========== 2. IQR 方法 ==========
def detect_iqr(series, k=1.5):
    """IQR 异常检测，k=1.5 标准，k=3 极端"""
    q1, q3 = series.quantile(0.25), series.quantile(0.75)
    iqr = q3 - q1
    lower, upper = q1 - k * iqr, q3 + k * iqr
    return (series < lower) | (series > upper), lower, upper

is_outlier_iqr, lo, hi = detect_iqr(df["amount"])
print(f"IQR 区间: [{lo:.2f}, {hi:.2f}]")
print(f"IQR 检出异常数: {is_outlier_iqr.sum()}")

# ========== 3. 孤立森林方法 ==========
iso = IsolationForest(n_estimators=100, contamination=0.01, random_state=42)
df["is_outlier_iso"] = iso.fit_predict(df[["amount"]]) == -1
print(f"孤立森林检出异常数: {df['is_outlier_iso'].sum()}")

# ========== 4. 两种方法对比 ==========
df["method"] = np.where(
    is_outlier_iqr & df["is_outlier_iso"], "both",
    np.where(is_outlier_iqr, "iqr_only",
    np.where(df["is_outlier_iso"], "iso_only", "normal"))
)
print(df[df["method"] != "normal"].sort_values("amount"))
```

### 4.5 异常值处理：删除 vs 截断 vs 标记

检测出异常后，处理方式视业务而定：

| 策略 | 做法 | 适用场景 |
|------|------|---------|
| 删除 | 直接 drop | 确认是脏数据（如测试订单、录入错误） |
| 截断（Winsorize） | 用边界值替换 | 是真实但极端的数据，不想丢信息 |
| 标记 | 新增 `is_outlier` 列保留 | 不确定，留给下游分析师决定 |

```python
# 删除
df_clean = df[~is_outlier_iqr].copy()

# 截断（Winsorize）：把超出边界的值压回边界
df["amount_winsor"] = df["amount"].clip(lower=lo, upper=hi)

# 标记：保留原值，新增标记列
df["amount_is_outlier"] = is_outlier_iqr
```

## 五、去重

### 5.1 精确去重（整行相同）

所有字段完全一致才算重复。最简单但最不常用——真实数据很少整行重复，往往是主键相同但部分字段不同。

```python
# pandas
df = df.drop_duplicates()

# Spark
df = df.dropDuplicates()
```

### 5.2 主键去重（业务主键相同）

按业务主键（如 `order_id`）去重，主键相同的行算重复。**问题**：保留哪一条？这引出保留策略。

### 5.3 模糊去重

当主键也不完全相同，但内容高度相似（如同一商品名略有差异的重复记录），需要用 SimHash/MinHash 等近似匹配。这是**课时28**的重点，本课时不展开，仅预告。

### 5.4 保留策略

| 策略 | 做法 | 适用场景 |
|------|------|---------|
| 保留最新 | 按 update_time 取最新 | 数据被多次更新，要最新状态 |
| 保留最旧 | 按 create_time 取最早 | 要原始记录 |
| 保留第一条 | 按入库顺序取第一条 | 任意保留，简单 |
| 保留最完整 | 非空字段最多的那条 | 缺失较多场景 |

### 5.5 代码示例：Spark dropDuplicates + 窗口函数保留最新

```python
from pyspark.sql import SparkSession, functions as F, Window

spark = SparkSession.builder.appName("DedupDemo").getOrCreate()

df = spark.read.parquet("/warehouse/ods/ods_order_info")

# ========== 方法1：dropDuplicates（简单，但不保证保留哪条） ==========
# 可指定 subset 按主键去重，但 Spark 不保证保留顺序
df_dedup1 = df.dropDuplicates(["order_id"])

# ========== 方法2：窗口函数精确控制保留策略 ==========
# 需求：order_id 重复时，保留 update_time 最新的一条；若时间也相同，保留 amount 最大的
w = Window.partitionBy("order_id").orderBy(
    F.col("update_time").desc_nulls_last(),
    F.col("amount").desc_nulls_last()
)

df_dedup2 = (
    df.withColumn("rn", F.row_number().over(w))
      .filter(F.col("rn") == 1)
      .drop("rn")
)

# ========== 方法3：保留非空字段最多的那条（最完整） ==========
# 统计每行非空字段数
cols = df.columns
df_with_cnt = df.withColumn(
    "non_null_cnt",
    F.size(F.array(*[F.when(F.col(c).isNull(), None).otherwise(c) for c in cols]))
)
w2 = Window.partitionBy("order_id").orderBy(F.col("non_null_cnt").desc())
df_dedup3 = (
    df_with_cnt.withColumn("rn", F.row_number().over(w2))
               .filter(F.col("rn") == 1)
               .drop("rn", "non_null_cnt")
)

df_dedup2.write.mode("overwrite").saveAsTable("dwd.dwd_order_info_dedup")
```

> **方法论提示**：去重一定要先想清楚"业务主键是什么"和"保留哪一条"。直接 `dropDuplicates()` 不指定策略，结果不可复现（Spark 各次执行保留的行可能不同），生产环境严禁裸用。

## 六、格式不统一

### 6.1 日期格式统一

同一字段出现多种写法，是采集自不同系统的典型症状：

```
"2024-01-01"        ISO 标准
"2024/1/1"          斜杠 + 不补零
"20240101"          紧凑数字串
"2024-01-01 10:00"  带时间
"2024年1月1日"       中文格式
```

### 6.2 手机号格式统一

```
"13800138000"       纯数字
"138-0013-8000"     横线分隔
"138 0013 8000"     空格分隔
"+86 13800138000"   带国家码
"0086-13800138000"  国际拨号格式
```

### 6.3 金额单位统一

```
"199.00"    元
"1.99"      百元（某些系统以分为单位存为 19900）
"0.0199"    万元
"19900"     分
```

### 6.4 代码示例：用正则和 pandas 标准化

```python
import pandas as pd
import re

df = pd.DataFrame({
    "order_id": [1001, 1002, 1003, 1004, 1005],
    "create_time": ["2024-01-01", "2024/1/1", "20240103", "2024年1月4日", "2024-01-05 10:00"],
    "phone": ["13800138000", "138-0013-8000", "+86 13800138002", "0086-13800138003", "138 0013 8004"],
    "amount": ["199.00", "1.99", "19900", "0.0199", "299.00"],   # 单位混乱
    "amount_unit": ["元", "百元", "分", "万元", "元"],
})

# ========== 1. 日期统一为 YYYY-MM-DD ==========
def normalize_date(s):
    s = str(s).strip()
    # 用正则提取年月日，兼容多种分隔符和中文
    m = re.search(r'(\d{4})\D*(\d{1,2})\D*(\d{1,2})', s)
    if m:
        y, mo, d = m.groups()
        return f"{int(y):04d}-{int(mo):02d}-{int(d):02d}"
    return None

df["create_time_std"] = df["create_time"].apply(normalize_date)

# ========== 2. 手机号统一为 11 位纯数字 ==========
def normalize_phone(s):
    s = str(s)
    # 只保留数字
    digits = re.sub(r'\D', '', s)
    # 去掉国家码 86 / 0086
    if len(digits) > 11 and digits.startswith('86'):
        digits = digits[-11:]
    elif len(digits) > 11 and digits.startswith('0086'):
        digits = digits[-11:]
    if len(digits) == 11:
        return digits
    return None  # 长度不对，标记为非法

df["phone_std"] = df["phone"].apply(normalize_phone)

# ========== 3. 金额统一为"元" ==========
unit_to_yuan = {
    "元": 1.0,
    "百元": 100.0,
    "分": 0.01,
    "万元": 10000.0,
}

def to_yuan(amount_str, unit):
    """把任意单位的金额换算成元"""
    try:
        return float(amount_str) * unit_to_yuan.get(unit, 1.0)
    except (ValueError, TypeError):
        return None

df["amount_yuan"] = df.apply(lambda r: to_yuan(r["amount"], r["amount_unit"]), axis=1)

print(df[["order_id", "create_time", "create_time_std",
          "phone", "phone_std", "amount", "amount_unit", "amount_yuan"]])
```

## 七、逻辑矛盾

### 7.1 业务规则校验

字段值或字段间违反业务规则。这类问题用统计方法查不出来，必须用规则：

```
时间规则：  end_time >= start_time
             pay_time 在 create_time 之后
             finish_time 在 pay_time 之后
年龄规则：  办信用卡 age >= 18
             退休 age <= 65（部分场景）
金额规则：  payment_amount <= total_amount
             refund_amount <= payment_amount
枚举规则：  订单状态流转：已取消 → 不能变成 已支付
```

### 7.2 跨字段一致性

| 一致性 | 规则 | 示例矛盾 |
|--------|------|---------|
| 省份-城市 | 城市必须属于该省份 | province=北京, city=上海 |
| 邮编-地区 | 邮编前两位对应省份 | 北京邮编 100000，却填 200000（上海） |
| 身份证-生日 | 身份证第 7-14 位 = 生日 | 身份证 11010519900101xxxx，birthday=1985-01-01 |
| 身份证-性别 | 第 17 位奇数=男，偶数=女 | 身份证末位奇数，性别却填女 |

### 7.3 代码示例：用 Spark SQL 校验逻辑矛盾

```python
from pyspark.sql import SparkSession, functions as F

spark = SparkSession.builder.appName("LogicCheck").getOrCreate()

df = spark.read.parquet("/warehouse/ods/ods_order_info")
df.createOrReplaceTempView("ods_order")

# ========== 1. 用 SQL 表达所有逻辑校验，结果存成"质量异常表" ==========
spark.sql("""
    SELECT
        order_id,
        -- 每条记录可能命中多个矛盾，用 CASE 标记
        CASE WHEN pay_time < create_time
             THEN 'pay_before_create' END AS err_pay_time,
        CASE WHEN finish_time < pay_time
             THEN 'finish_before_pay' END AS err_finish_time,
        CASE WHEN payment_amount > total_amount
             THEN 'payment_exceed_total' END AS err_payment,
        CASE WHEN province = '北京' AND city <> '北京' AND city IS NOT NULL
             THEN 'province_city_mismatch' END AS err_province_city,
        CASE WHEN refund_amount > payment_amount
             THEN 'refund_exceed_payment' END AS err_refund
    FROM ods_order
""").createOrReplaceTempView("order_errors")

# ========== 2. 汇总每种错误的命中数 ==========
spark.sql("""
    SELECT
        COUNT(*) AS total_rows,
        SUM(CASE WHEN err_pay_time IS NOT NULL THEN 1 ELSE 0 END) AS cnt_pay_time,
        SUM(CASE WHEN err_finish_time IS NOT NULL THEN 1 ELSE 0 END) AS cnt_finish_time,
        SUM(CASE WHEN err_payment IS NOT NULL THEN 1 ELSE 0 END) AS cnt_payment,
        SUM(CASE WHEN err_province_city IS NOT NULL THEN 1 ELSE 0 END) AS cnt_province_city,
        SUM(CASE WHEN err_refund IS NOT NULL THEN 1 ELSE 0 END) AS cnt_refund
    FROM order_errors
""").show()

# ========== 3. 处理：矛盾记录进死信表，主表只留合法记录 ==========
# 死信表：所有有错误的记录，人工/规则修复
spark.sql("""
    SELECT o.*
    FROM ods_order o
    JOIN order_errors e ON o.order_id = e.order_id
    WHERE e.err_pay_time IS NOT NULL
       OR e.err_finish_time IS NOT NULL
       OR e.err_payment IS NOT NULL
       OR e.err_province_city IS NOT NULL
       OR e.err_refund IS NOT NULL
""").write.mode("overwrite").saveAsTable("dwd.dwd_order_info_dead_letter")

# 主表：只写合法记录
spark.sql("""
    SELECT o.*
    FROM ods_order o
    LEFT JOIN order_errors e ON o.order_id = e.order_id
    WHERE e.order_id IS NULL
""").write.mode("overwrite").saveAsTable("dwd.dwd_order_info_clean")
```

> **方法论提示**：逻辑矛盾记录**不要静默删除**，必须进"死信表（Dead Letter）"留痕。死信表是数据治理的审计依据，也方便后续分析"哪些渠道/哪些字段最常出错"，反向推动采集端改进。

## 八、编码问题（中文环境特有）

### 8.1 常见编码问题

| 问题 | 现象 | 原因 |
|------|------|------|
| UTF-8/GBK 混淆 | "姝戠敤鎴?" 乱码 | 文件以 GBK 编码，却用 UTF-8 读 |
| BOM 头 | 首行首字符前多出 `\ufeff` | Windows 的 Notepad 存 UTF-8 时加 BOM |
| 零宽字符 | 字符串看似相等却匹配失败 | 复制粘贴引入 U+200B/U+FEFF |
| 半角全角 | "１３８" vs "138" | 输入法全角数字 |

### 8.2 乱码识别与修复

```
乱码修复思路：

1. 检测：用 chardet/cchardet 自动探测原始编码
2. 修复：按探测到的编码重新 decode，再 encode 成 UTF-8
3. 兜底：decode 时加 errors='replace'，避免抛异常中断处理
4. 验证：修复后抽样人工核对
```

### 8.3 代码示例：chardet 检测编码、encode/decode 修复

```python
# 依赖：pip install chardet
import chardet
import pandas as pd

# ========== 1. 检测文件编码 ==========
def detect_file_encoding(file_path, sample_size=10000):
    """读取文件前 N 字节探测编码"""
    with open(file_path, 'rb') as f:
        raw = f.read(sample_size)
    result = chardet.detect(raw)
    return result['encoding'], result['confidence']

enc, conf = detect_file_encoding("dirty_data.csv")
print(f"检测到编码: {enc} (置信度 {conf:.0%})")

# 用探测到的编码读文件，避免乱码
df = pd.read_csv("dirty_data.csv", encoding=enc)

# ========== 2. 处理 BOM 头 ==========
# 用 utf-8-sig 读会自动去掉 BOM
df = pd.read_csv("dirty_data.csv", encoding="utf-8-sig")

# 或对已读入的字符串手动去 BOM
df["col"] = df["col"].str.replace("\ufeff", "", regex=False)

# ========== 3. 修复单列的乱码（"encode-then-decode"技巧） ==========
# 场景：字符串已经被错误的编码读进来了，呈现为乱码
# 原理：先 encode 回错误编码的字节，再用正确编码 decode
def fix_mojibake(s, wrong_enc="utf-8", right_enc="gbk"):
    """
    修复"用 wrong_enc 读了 right_enc 文件"产生的乱码
    例：s='姝戠敤鎴?' 是用 utf-8 读 gbk 文件的结果
        s.encode('utf-8').decode('gbk') 还原
    """
    try:
        return s.encode(wrong_enc).decode(right_enc)
    except (UnicodeEncodeError, UnicodeDecodeError):
        return s  # 无法修复则原样返回

# ========== 4. 清除零宽字符 ==========
import re
ZERO_WIDTH = re.compile(r'[\u200B-\u200D\uFEFF]')  # 零宽空格/零宽连字符/BOM

def strip_zero_width(s):
    if isinstance(s, str):
        return ZERO_WIDTH.sub('', s)
    return s

df = df.applymap(strip_zero_width)

# ========== 5. 全角转半角 ==========
def full_to_half(s):
    """全角字符转半角（数字、字母、标点）"""
    if not isinstance(s, str):
        return s
    result = []
    for ch in s:
        code = ord(ch)
        # 全角空格
        if code == 0x3000:
            result.append(' ')
        # 全角字符 (0xFF01-0xFF5E) 转半角
        elif 0xFF01 <= code <= 0xFF5E:
            result.append(chr(code - 0xFEE0))
        else:
            result.append(ch)
    return ''.join(result)

df["phone"] = df["phone"].apply(full_to_half)
```

> **方法论提示**：编码问题**预防优于修复**。在采集层就强制约定"所有文本以 UTF-8 无 BOM 落地"，比事后修复成本低得多。chardet 检测有误判率（尤其样本小或混合编码时），修复后必须抽样核对。

## 九、清洗流水线设计

### 9.1 清洗步骤的顺序

步骤顺序很重要，做错顺序会导致重复劳动或错误传播：

```
推荐顺序：

1. 编码修复        ← 第一步，否则后续所有字符串操作都不可靠
      ↓
2. 格式标准化      ← 把日期/手机号/金额统一，让后续规则能正确比较
      ↓
3. 缺失值处理      ← 占位符转 NULL，再决定删除/填充
      ↓
4. 去重            ← 在格式统一后去重，避免"同一记录因格式不同没去重"
      ↓
5. 异常值检测      ← 去重后再检测，避免重复行干扰统计
      ↓
6. 逻辑矛盾校验    ← 最后做，因为需要所有字段都已清洗到位
      ↓
7. 写入死信表/主表
```

**为什么去重在缺失处理之后、异常检测之前？**
- 去重前做缺失处理：重复行的缺失会被重复填充，浪费算力；
- 去重后做异常检测：重复行会扭曲分布（同一异常被算多次），影响 IQR/均值计算。

### 9.2 用 Pipeline 封装清洗逻辑

把清洗步骤封装成可复用、可测试的流水线，避免散落的脚本。

**pandas + sklearn Pipeline 示例**：

```python
import pandas as pd
import numpy as np
from sklearn.base import BaseEstimator, TransformerMixin
from sklearn.pipeline import Pipeline
import re


# ========== 自定义 Transformer：每步清洗逻辑封装成一个类 ==========

class EncodingCleaner(BaseEstimator, TransformerMixin):
    """编码清洗：去 BOM、去零宽字符"""
    def fit(self, X, y=None):
        return self

    def transform(self, X):
        X = X.copy()
        ZW = re.compile(r'[\u200B-\u200D\uFEFF]')
        for col in X.select_dtypes(include="object").columns:
            X[col] = X[col].apply(
                lambda s: ZW.sub('', s).replace('\ufeff', '')
                if isinstance(s, str) else s
            )
        return X


class FormatNormalizer(BaseEstimator, TransformerMixin):
    """格式标准化：手机号、日期"""
    def fit(self, X, y=None):
        return self

    def transform(self, X):
        X = X.copy()
        if "phone" in X.columns:
            X["phone"] = X["phone"].apply(self._normalize_phone)
        if "create_time" in X.columns:
            X["create_time"] = X["create_time"].apply(self._normalize_date)
        return X

    @staticmethod
    def _normalize_phone(s):
        if pd.isna(s):
            return None
        digits = re.sub(r'\D', '', str(s))
        if len(digits) > 11 and digits.startswith('86'):
            digits = digits[-11:]
        return digits if len(digits) == 11 else None

    @staticmethod
    def _normalize_date(s):
        m = re.search(r'(\d{4})\D*(\d{1,2})\D*(\d{1,2})', str(s))
        if m:
            y, mo, d = m.groups()
            return f"{int(y):04d}-{int(mo):02d}-{int(d):02d}"
        return None


class MissingHandler(BaseEstimator, TransformerMixin):
    """缺失处理：占位符转 NULL + 按策略填充"""
    PLACEHOLDERS = ["N/A", "null", "-", "", "未知"]

    def fit(self, X, y=None):
        # fit 阶段计算填充值，避免数据泄漏
        self.fill_values_ = {}
        for col in X.columns:
            if X[col].dtype in [np.float64, np.int64]:
                self.fill_values_[col] = X[col].median()
        return self

    def transform(self, X):
        X = X.copy()
        # 占位符转 NULL
        for col in X.select_dtypes(include="object").columns:
            s = X[col].astype(str).str.strip()
            X[col] = X[col].where(~s.isin(self.PLACEHOLDERS) & (s != "nan"), np.nan)
        # 数值列用 fit 阶段算好的中位数填充
        for col, val in self.fill_values_.items():
            X[col] = X[col].fillna(val)
        return X


class Deduplicator(BaseEstimator, TransformerMixin):
    """去重：按主键保留第一条"""
    def __init__(self, key="order_id"):
        self.key = key

    def fit(self, X, y=None):
        return self

    def transform(self, X):
        return X.drop_duplicates(subset=[self.key], keep="first")


# ========== 组装 Pipeline ==========
clean_pipeline = Pipeline([
    ("encoding", EncodingCleaner()),
    ("format", FormatNormalizer()),
    ("missing", MissingHandler()),
    ("dedup", Deduplicator(key="order_id")),
])

# ========== 使用 ==========
df_raw = pd.read_csv("dirty_orders.csv")
df_clean = clean_pipeline.fit_transform(df_raw)

print(f"清洗前: {len(df_raw)} 行")
print(f"清洗后: {len(df_clean)} 行")

# Pipeline 可持久化，新数据复用同一套清洗逻辑
import joblib
joblib.dump(clean_pipeline, "clean_pipeline.pkl")
```

> **方法论提示**：Pipeline 的 `fit` 只能在训练集上做（计算中位数、众数等），`transform` 应用到新数据。这样能避免"数据泄漏"——用测试集/线上数据的统计量填充训练集，导致评估失真。生产环境把 `fit` 出来的参数（如中位数）持久化，线上清洗时只调 `transform`。

## 十一、小结

| 问题类型 | 检测方法 | 处理策略 | 工具 |
|---------|---------|---------|------|
| 缺失 | `isnull()` / 空值率统计 / 占位符字典 | 删除 / 填充（均值中位数众数）/ 插值 | pandas `dropna`/`fillna`/`interpolate`，Spark `na.drop`/`na.fill` |
| 异常 | IQR / Z-score / 3σ / 业务规则 / 孤立森林 | 删除 / 截断（Winsorize）/ 标记 | sklearn `IsolationForest`，Spark `approxQuantile` |
| 重复 | 主键计数 / `duplicated()` | 精确去重 / 主键去重 / 保留最新最旧最完整 | pandas `drop_duplicates`，Spark `dropDuplicates` + 窗口函数 |
| 格式不统一 | Profiling 看唯一值 / 正则探测 | 正则标准化 / 字典映射 | pandas + `re`，Spark `regexp_replace` |
| 逻辑矛盾 | 业务规则 SQL / 跨字段校验 | 进死信表 / 自动修复 / 标记 | Spark SQL，pandas `query` |
| 编码问题 | chardet 检测 / 抽样人工看 | `utf-8-sig` 去 BOM / encode-decode 修复 / 零宽字符清除 | `chardet`，`encode`/`decode` |

**核心工程原则**：
1. **顺序很重要**：编码 → 格式 → 缺失 → 去重 → 异常 → 逻辑矛盾，做错顺序会传播错误
2. **不要静默删除**：所有被剔除的记录进死信表留痕，方便审计和反向推动采集改进
3. **预防优于修复**：编码、格式问题尽量在采集层强制约束，事后修复成本高
4. **Pipeline 化**：清洗逻辑封装成可复用、可测试、可持久化的 Pipeline，避免散落脚本
5. **fit/transform 分离**：统计量（中位数、IQR 边界）只在训练集 fit，避免数据泄漏
