# 项目10：多渠道用户反馈清洗入仓

> **项目时长**：10h | **项目类型**：独立完成 | **前置**：课时24-29 | **难度**：★★★★★ L2综合项目

---

## 一、项目描述

### 1.1 业务背景

某电商公司的用户反馈散落在三个渠道，运营团队每周要花两天时间手工拼接数据，仍然无法回答"某个核心用户在我们这里的整体反馈画像是什么"。问题根源在于：

1. **身份割裂**：同一个用户在 APP 用手机号注册，在客服会话里只留了微信 OpenID，在邮件工单里用邮箱。三份数据互相不知道对方是同一个人。
2. **值不统一**：地区名有"北京"/"北京市"/"BJ"/"Beijing"四种写法，反馈类型字段各渠道自定义分类，商品名写法五花八门。
3. **格式混乱**：APP 表单是结构化 JSON，客服聊天是非结构化 txt 导出，邮件是 .eml 文件，schema 完全不一致。

### 1.2 三个数据源

| 渠道 | 来源形态 | 关键字段 | 日均量 | 结构化程度 |
|------|---------|---------|--------|-----------|
| APP 内置反馈表单 | HTTP API 拉取（JSON） | user_id / phone / feedback_text / submit_time | 10万条 | 高（结构化） |
| 客服聊天记录 | txt 文件导出 | session_id / openid / phone(可空) / chat_text / chat_time | 50万条 | 低（非结构化） |
| 邮件工单 | .eml 文件（IMAP 拉取） | ticket_id / email / subject / body / create_time | 1万条 | 中（半结构化） |

### 1.3 项目目标

构建端到端清洗入仓流水线，将三个异构渠道的反馈数据清洗、ID Mapping 打通用户身份、标准化枚举值后，统一入仓到 DWD 层，输出一张可供运营直接分析的 `dwd_user_feedback_clean` 表。

核心交付价值：把"三个渠道三种身份三种写法"的脏数据，变成"一个 global_user_id + 标准枚举值 + 去重文本"的可分析明细表。

## 三、数据流设计

### 3.1 数据流图

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│  APP 反馈    │  │  客服聊天    │  │  邮件工单    │
│  HTTP API   │  │  txt 文件    │  │  .eml 文件  │
└──────┬──────┘  └──────┬──────┘  └──────┬──────┘
       │                │                │
       ▼                ▼                ▼
┌─────────────────────────────────────────────────┐
│              ODS 原始层（三张表，按 dt 分区）        │
│  ods_app_feedback_raw  ods_chat_raw  ods_email_raw│
└──────────────────────┬──────────────────────────┘
                       │ 字段化解析 + 初步清洗
                       ▼
┌─────────────────────────────────────────────────┐
│              清洗中间层（统一 schema）               │
│  统一字段：source_channel / raw_id / identity_phone │
│           identity_email / identity_openid        │
│           feedback_text / feedback_time           │
└──────────────────────┬──────────────────────────┘
                       │ ID Mapping + 枚举标准化 + 文本去重
                       ▼
┌─────────────────────────────────────────────────┐
│         DWD 明细层（含 global_user_id）             │
│         dwd_user_feedback_clean                   │
└──────────────────────┬──────────────────────────┘
                       │ 按渠道/类型/地区汇总
                       ▼
┌─────────────────────────────────────────────────┐
│              DWS 汇总层                            │
│  dws_feedback_channel_day    （渠道日汇总）         │
│  dws_feedback_type_day       （反馈类型日汇总）     │
│  dws_feedback_province_day    （地区日汇总）         │
└─────────────────────────────────────────────────┘
```

### 3.2 关键设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 中间层是否落表 | 落到 ODS 后直接在内存清洗 | 日均 61 万条不大，Spark 内存处理足够，避免过多落盘 IO |
| ID Mapping 算法 | Union-Find 联通分量 | 链式传递场景天然适合，比 GraphFrame 部署轻 |
| 枚举标准化 | 精确字典优先 + rapidfuzz 模糊兜底 | 精确匹配覆盖 90% 主流写法，模糊匹配处理长尾 |
| 文本去重 | SimHash 64位 + 汉明距离阈值 3 | 量级适中，SimHash 召回快，比 MinHash 实现简单 |

```python
"""
collect_app_feedback.py — 从 APP 反馈 API 拉取数据

功能：
  1. 调用反馈系统 HTTP API 拉取昨日全量数据
  2. 解析 JSON 响应为统一 DataFrame
  3. 写入 ODS 层 ods_app_feedback_raw 表（按 dt 分区）
"""
import requests
import pandas as pd
from datetime import datetime, timedelta
from pyhive import hive

# API 配置
API_BASE = "http://feedback-service/api/v1"
API_TOKEN = "your_token_here"  # 实际从配置中心或环境变量读取
PAGE_SIZE = 1000

YESTERDAY = (datetime.now() - timedelta(days=1)).strftime("%Y-%m-%d")


def fetch_feedback_page(dt, page):
    """拉取单页反馈数据"""
    headers = {"Authorization": f"Bearer {API_TOKEN}"}
    params = {"date": dt, "page": page, "size": PAGE_SIZE}
    resp = requests.get(f"{API_BASE}/feedbacks", headers=headers, params=params, timeout=30)
    resp.raise_for_status()
    return resp.json()


def collect_app_feedback(dt):
    """采集 APP 反馈全量数据"""
    all_records = []
    page = 1
    while True:
        data = fetch_feedback_page(dt, page)
        records = data.get("items", [])
        if not records:
            break
        all_records.extend(records)
        if len(records) < PAGE_SIZE:
            break
        page += 1

    # 转为 DataFrame，统一字段名
    df = pd.DataFrame(all_records)
    if not df.empty:
        df = df.rename(columns={
            "user_id": "app_user_id",
            "feedback_text": "feedback_text",
            "submit_time": "feedback_time",
        })
        df["source_channel"] = "APP"
    return df


def load_to_ods(df, dt):
    """写入 ODS 层"""
    # 实际项目通过 Spark 或 Hive JDBC 写入
    # 此处仅展示框架
    print(f"[ODS] APP 反馈写入 {len(df)} 条, dt={dt}")


if __name__ == "__main__":
    df = collect_app_feedback(YESTERDAY)
    load_to_ods(df, YESTERDAY)
```

#### 1.2 客服聊天记录采集脚本

```python
"""
collect_chat_log.py — 解析客服聊天 txt 导出文件

导出文件格式示例：
  [2025-07-14 10:23:15] [客服:王芳] [session:S5891] [openid:oXxx_abc] [phone:13800138000]
  用户：我昨天付款一直转圈
  [2025-07-14 10:23:45] [客服:王芳] [session:S5891]
  客服：您好，请提供一下订单号

功能：
  1. 按行解析 txt 文件，区分消息头和消息内容
  2. 提取 session_id / openid / phone / 发送方 / 时间 / 内容
  3. 输出统一 DataFrame
"""
import re
import pandas as pd
from datetime import datetime, timedelta

YESTERDAY = (datetime.now() - timedelta(days=1)).strftime("%Y-%m-%d")

# 消息头正则：[时间] [发送方:xxx] [session:xxx] [openid:xxx] [phone:xxx]
HEADER_PATTERN = re.compile(
    r"\[(?P<time>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})\]"
    r"\s*\[(?P<role>[^:]+):(?P<role_name>[^\]]+)\]"
    r"\s*\[session:(?P<session_id>[^\]]+)\]"
    r"(?:\s*\[openid:(?P<openid>[^\]]+)\])?"
    r"(?:\s*\[phone:(?P<phone>[^\]]+)\])?"
)


def parse_chat_file(file_path):
    """解析单个聊天导出文件"""
    records = []
    current_header = None
    current_content_lines = []

    with open(file_path, "r", encoding="utf-8") as f:
        for line in f:
            line = line.rstrip("\n")
            match = HEADER_PATTERN.match(line)
            if match:
                # 保存上一条消息
                if current_header is not None:
                    current_header["chat_text"] = "\n".join(current_content_lines).strip()
                    records.append(current_header)
                # 开始新消息
                current_header = match.groupdict()
                current_header["sender"] = "客服" if "客服" in match.group("role") else "用户"
                current_header["msg_type"] = "text"
                current_content_lines = []
            else:
                # 消息正文行（去掉"用户："/"客服："前缀）
                content = re.sub(r"^(用户|客服)：", "", line)
                current_content_lines.append(content)

    # 保存最后一条
    if current_header is not None:
        current_header["chat_text"] = "\n".join(current_content_lines).strip()
        records.append(current_header)

    df = pd.DataFrame(records)
    if not df.empty:
        df["source_channel"] = "CHAT"
        df["feedback_time"] = df["time"]
    return df


if __name__ == "__main__":
    # 实际从 HDFS 或 NFS 读取导出文件
    file_path = f"/data/chat_export/{YESTERDAY}.txt"
    df = parse_chat_file(file_path)
    print(f"[ODS] 客服聊天解析 {len(df)} 条")
```

#### 1.3 邮件工单采集脚本

```python
"""
collect_email_ticket.py — 用 IMAP 拉取邮件并解析 .eml

功能：
  1. 通过 imaplib 连接邮箱拉取昨日工单邮件
  2. 用 email 模块解析发件人/主题/正文
  3. 输出统一 DataFrame
"""
import imaplib
import email
from email.header import decode_header
import pandas as pd
from datetime import datetime, timedelta

IMAP_HOST = "imap.exmail.example.com"
IMAP_USER = "ticket@company.com"
IMAP_PASS = "your_password"  # 实际从配置中心读取

YESTERDAY = (datetime.now() - timedelta(days=1)).strftime("%d-%b-%Y")


def decode_mime_header(value):
    """解码 MIME 编码的邮件头"""
    if value is None:
        return ""
    parts = decode_header(value)
    decoded = []
    for content, charset in parts:
        if isinstance(content, bytes):
            decoded.append(content.decode(charset or "utf-8", errors="ignore"))
        else:
            decoded.append(content)
    return "".join(decoded)


def extract_email_body(msg):
    """提取邮件正文（优先 text/plain，其次 text/html 去标签）"""
    if msg.is_multipart():
        for part in msg.walk():
            if part.get_content_type() == "text/plain":
                return part.get_payload(decode=True).decode(
                    part.get_content_charset() or "utf-8", errors="ignore")
        # 退而求其次取 html
        for part in msg.walk():
            if part.get_content_type() == "text/html":
                html = part.get_payload(decode=True).decode(
                    part.get_content_charset() or "utf-8", errors="ignore")
                # 简单去标签，实际用 BeautifulSoup 更稳
                import re
                return re.sub(r"<[^>]+>", "", html).strip()
    else:
        return msg.get_payload(decode=True).decode(
            msg.get_content_charset() or "utf-8", errors="ignore")


def collect_email_tickets(date_str):
    """拉取指定日期的邮件工单"""
    mail = imaplib.IMAP4_SSL(IMAP_HOST)
    mail.login(IMAP_USER, IMAP_PASS)
    mail.select("INBOX")

    # 按日期搜索
    status, data = mail.search(None, f'(ON {date_str})')
    ids = data[0].split()

    records = []
    for eid in ids:
        status, msg_data = mail.fetch(eid, "(RFC822)")
        msg = email.message_from_bytes(msg_data[0][1])

        from_header = decode_mime_header(msg.get("From", ""))
        # 提取 email 地址
        email_match = re.search(r"[\w.+-]+@[\w-]+\.[\w.-]+", from_header)
        sender_email = email_match.group(0) if email_match else ""

        records.append({
            "ticket_id": msg.get("Message-ID", "").strip("<>"),
            "email": sender_email,
            "subject": decode_mime_header(msg.get("Subject", "")),
            "body": extract_email_body(msg),
            "feedback_time": msg.get("Date", ""),
            "source_channel": "EMAIL",
        })

    mail.logout()
    return pd.DataFrame(records)


import re  # 顶部已用，此处兜底
if __name__ == "__main__":
    df = collect_email_tickets(YESTERDAY)
    print(f"[ODS] 邮件工单拉取 {len(df)} 条")
```

### 阶段2：非结构化解析（2h）

> 对应课时25。目标：三个渠道数据解析成统一 schema 的 DataFrame，便于后续清洗。

#### 2.1 统一 Schema 设计

```
统一反馈记录 schema（清洗中间层）：
  - source_channel      渠道来源（APP/CHAT/EMAIL）
  - raw_id              原始记录ID（app_user_id / session_id / ticket_id）
  - identity_phone      身份-手机号（可空）
  - identity_email      身份-邮箱（可空）
  - identity_openid     身份-微信OpenID（可空）
  - identity_device_id  身份-设备ID（可空，APP渠道）
  - feedback_text       反馈正文（统一为纯文本）
  - feedback_time       反馈时间（统一为 yyyy-MM-dd HH:mm:ss）
  - raw_payload         原始报文（JSON字符串，用于回溯）
```

#### 2.2 统一解析器

```python
"""
normalize_schema.py — 将三渠道数据统一为相同 schema 的 DataFrame

功能：
  1. APP 反馈：字段重命名 + 时间格式化
  2. 聊天记录：合并同一 session 的多条消息为一条反馈
  3. 邮件：subject + body 拼接为 feedback_text
"""
import pandas as pd
from datetime import datetime


def normalize_app(df_app):
    """APP 反馈归一化"""
    return pd.DataFrame({
        "source_channel": "APP",
        "raw_id": df_app["app_user_id"].astype(str),
        "identity_phone": df_app.get("phone"),
        "identity_email": df_app.get("email"),       # APP 渠道可能也绑定了邮箱
        "identity_openid": None,
        "identity_device_id": df_app.get("device_id"),
        "feedback_text": df_app["feedback_text"],
        "feedback_time": pd.to_datetime(df_app["feedback_time"], errors="coerce"),
        "raw_payload": df_app.apply(lambda r: r.to_json(), axis=1),
    })


def normalize_chat(df_chat):
    """聊天记录归一化：合并同一 session 的用户消息"""
    # 只保留用户发的消息（客服消息不计入反馈）
    df_user = df_chat[df_chat["sender"] == "用户"].copy()
    # 同一 session 的多条用户消息合并为一条反馈
    df_merged = df_user.groupby("session_id").agg({
        "openid": "first",
        "phone": "first",
        "chat_text": lambda texts: " | ".join(t for t in texts if t),
        "feedback_time": "min",   # 取会话最早时间作为反馈时间
    }).reset_index()

    return pd.DataFrame({
        "source_channel": "CHAT",
        "raw_id": df_merged["session_id"].astype(str),
        "identity_phone": df_merged["phone"],
        "identity_email": None,
        "identity_openid": df_merged["openid"],
        "identity_device_id": None,
        "feedback_text": df_merged["chat_text"],
        "feedback_time": pd.to_datetime(df_merged["feedback_time"], errors="coerce"),
        "raw_payload": df_merged.apply(lambda r: r.to_json(), axis=1),
    })


def normalize_email(df_email):
    """邮件归一化：subject + body 拼接"""
    feedback_text = df_email.apply(
        lambda r: f"{r['subject']}：{r['body']}", axis=1)

    return pd.DataFrame({
        "source_channel": "EMAIL",
        "raw_id": df_email["ticket_id"].astype(str),
        "identity_phone": None,
        "identity_email": df_email["email"],
        "identity_openid": None,
        "identity_device_id": None,
        "feedback_text": feedback_text,
        "feedback_time": pd.to_datetime(df_email["feedback_time"], errors="coerce"),
        "raw_payload": df_email.apply(lambda r: r.to_json(), axis=1),
    })


def normalize_all(df_app, df_chat, df_email):
    """合并三渠道为统一 DataFrame"""
    frames = [normalize_app(df_app), normalize_chat(df_chat), normalize_email(df_email)]
    return pd.concat(frames, ignore_index=True)
```

### 阶段3：数据清洗（1.5h）

> 对应课时26。目标：缺失值兜底、格式统一、重复去除。

```python
"""
clean_feedback.py — 数据清洗脚本

功能：
  1. 缺失值处理：手机号缺失的用 openid 兜底标记
  2. 格式统一：手机号去 +86 前缀、时间格式统一
  3. 去重：同一用户同一内容 5 分钟内重复提交
  4. 异常过滤：反馈正文为空或长度<2 的剔除
"""
import re
import pandas as pd
from datetime import timedelta


def clean_phone(phone):
    """手机号格式统一：去 +86、去空格、去横线"""
    if pd.isna(phone) or phone == "":
        return None
    phone = str(phone).strip()
    # 去 +86 前缀
    phone = re.sub(r"^\+86", "", phone)
    # 去空格和横线
    phone = re.sub(r"[\s\-]", "", phone)
    # 校验 11 位
    if re.match(r"^1[3-9]\d{9}$", phone):
        return phone
    return None


def normalize_time(ts):
    """时间格式统一为 yyyy-MM-dd HH:mm:ss"""
    if pd.isna(ts):
        return None
    try:
        return pd.Timestamp(ts).strftime("%Y-%m-%d %H:%M:%S")
    except Exception:
        return None


def fill_missing_identity(df):
    """缺失身份兜底：手机号缺失时用 openid 或 email 作为兜底标识"""
    # 同一 raw_id 在不同记录可能携带不同身份，这里做简单兜底
    # 真正的身份打通在阶段4 ID Mapping 完成
    df["identity_phone"] = df["identity_phone"].apply(clean_phone)
    # 至少要有一个身份标识，否则无法参与 ID Mapping
    df["has_any_identity"] = df[[
        "identity_phone", "identity_email", "identity_openid", "identity_device_id"
    ]].notna().any(axis=1)
    # 剔除没有任何身份标识的记录（无法分析）
    df = df[df["has_any_identity"]].copy()
    return df


def deduplicate(df):
    """去重：同一用户同一内容 5 分钟内重复提交"""
    # 排序便于时间窗口判断
    df = df.sort_values(["identity_phone", "feedback_time"]).copy()
    df["prev_time"] = df.groupby("identity_phone")["feedback_time"].shift(1)
    df["prev_text"] = df.groupby("identity_phone")["feedback_text"].shift(1)

    # 5 分钟内 + 文本完全相同 → 视为重复
    df["time_diff"] = (pd.to_datetime(df["feedback_time"]) -
                       pd.to_datetime(df["prev_time"])).dt.total_seconds()
    df["is_dup"] = (
        (df["time_diff"] <= 300) &
        (df["feedback_text"] == df["prev_text"])
    )
    return df[~df["is_dup"]].drop(columns=["prev_time", "prev_text", "time_diff", "is_dup"])


def clean_feedback(df):
    """清洗主流程"""
    print(f"[Clean] 输入 {len(df)} 条")

    # 1. 缺失身份兜底与剔除
    df = fill_missing_identity(df)
    print(f"[Clean] 身份兜底后 {len(df)} 条")

    # 2. 时间格式统一
    df["feedback_time"] = df["feedback_time"].apply(normalize_time)

    # 3. 反馈正文清洗
    df["feedback_text"] = df["feedback_text"].fillna("").str.strip()
    df = df[df["feedback_text"].str.len() >= 2]   # 过滤空内容或过短
    print(f"[Clean] 正文过滤后 {len(df)} 条")

    # 4. 去重
    df = deduplicate(df)
    print(f"[Clean] 去重后 {len(df)} 条")

    return df.reset_index(drop=True)
```

### 阶段4：ID Mapping（2h）

> 对应课时27。目标：用 Union-Find 算法打通三渠道用户身份，输出 `global_user_id`。

#### 4.1 问题形式化

```
记录1: APP    user_id=U10023, phone=13800138000
记录2: APP    user_id=U10023,                  email=a@x.com
记录3: CHAT   session=S5891,  phone=13800138000, openid=oXxx_abc
记录4: EMAIL  ticket=T2025,                     email=a@x.com
记录5: CHAT   session=S5892,  openid=oXxx_abc

链式传递：1-3(共享phone) → 3-5(共享openid) → 1-2(共享user_id) → 2-4(共享email)
结果：1/2/3/4/5 全部归为同一个 global_user_id
```

#### 4.2 Union-Find 实现

```python
"""
id_mapping.py — 跨渠道用户身份打通

功能：
  1. 抽取所有 (identity_type, identity_value) 对
  2. 用 Union-Find 找联通分量，每个联通分量分配一个 global_user_id
  3. 输出 user_id_mapping 表：raw_id → global_user_id
"""
import pandas as pd


class UnionFind:
    """并查集实现，支持链式传递的联通分量求解"""

    def __init__(self):
        self.parent = {}

    def find(self, x):
        """路径压缩查找根节点"""
        if x not in self.parent:
            self.parent[x] = x
            return x
        # 路径压缩
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        """合并两个集合"""
        rx, ry = self.find(x), self.find(y)
        if rx != ry:
            self.parent[rx] = ry

    def groups(self):
        """返回所有联通分量 {root: [members]}"""
        result = {}
        for x in self.parent:
            root = self.find(x)
            result.setdefault(root, []).append(x)
        return result


def build_identity_edges(df):
    """
    为每条记录抽取身份标识，构造边

    身份标识统一格式化为 (type, value)，例如：
      ("phone", "13800138000")
      ("email", "a@x.com")
      ("openid", "oXxx_abc")
    """
    edges = []   # (node_a, node_b) 表示两个节点属于同一用户
    identity_cols = {
        "identity_phone": "phone",
        "identity_email": "email",
        "identity_openid": "openid",
        "identity_device_id": "device_id",
    }

    for _, row in df.iterrows():
        # raw_id 作为节点
        raw_node = f"raw:{row['source_channel']}:{row['raw_id']}"
        for col, id_type in identity_cols.items():
            val = row.get(col)
            if pd.notna(val) and str(val).strip():
                id_node = f"{id_type}:{val}"
                edges.append((raw_node, id_node))
    return edges


def id_mapping(df):
    """执行 ID Mapping，为每条记录分配 global_user_id"""
    uf = UnionFind()
    edges = build_identity_edges(df)

    # 合并所有边
    for a, b in edges:
        uf.union(a, b)

    # 为每个联通分量分配 global_user_id
    groups = uf.groups()
    global_id_map = {}
    gid_counter = 1
    for root, members in groups.items():
        gid = f"G{gid_counter:08d}"
        gid_counter += 1
        for m in members:
            global_id_map[m] = gid

    # 给每条记录打上 global_user_id
    df = df.copy()
    df["global_user_id"] = df.apply(
        lambda r: global_id_map.get(
            f"raw:{r['source_channel']}:{r['raw_id']}", None),
        axis=1
    )
    return df


def build_mapping_table(df):
    """构建 user_id_mapping 表（可入仓 dim 层）"""
    mapping = df[["global_user_id", "source_channel", "raw_id",
                  "identity_phone", "identity_email",
                  "identity_openid", "identity_device_id"]].copy()
    mapping = mapping.drop_duplicates(subset=["global_user_id", "source_channel", "raw_id"])
    return mapping


if __name__ == "__main__":
    # 示例：构造测试数据验证链式传递
    test_data = pd.DataFrame([
        {"source_channel": "APP",   "raw_id": "U10023", "identity_phone": "13800138000",
         "identity_email": None, "identity_openid": None, "identity_device_id": None,
         "feedback_text": "x", "feedback_time": None},
        {"source_channel": "APP",   "raw_id": "U10023", "identity_phone": None,
         "identity_email": "a@x.com", "identity_openid": None, "identity_device_id": None,
         "feedback_text": "x", "feedback_time": None},
        {"source_channel": "CHAT",  "raw_id": "S5891", "identity_phone": "13800138000",
         "identity_email": None, "identity_openid": "oXxx_abc", "identity_device_id": None,
         "feedback_text": "x", "feedback_time": None},
        {"source_channel": "EMAIL", "raw_id": "T2025", "identity_phone": None,
         "identity_email": "a@x.com", "identity_openid": None, "identity_device_id": None,
         "feedback_text": "x", "feedback_time": None},
    ])
    result = id_mapping(test_data)
```

#### 5.3 标准化脚本

```python
"""
standardize_enum.py — 枚举值标准化

功能：
  1. 地区标准化：精确字典匹配 + rapidfuzz 模糊匹配兜底
  2. 反馈类型分类：关键词匹配（实际项目可用分类模型）
  3. 字典版本化：带 version 字段，可回溯
"""
import pandas as pd
from rapidfuzz import process, fuzz


class RegionStandardizer:
    """地区标准化器"""

    def __init__(self, dict_df, version="v1.0"):
        # 过滤出当前版本有效字典
        self.dict_df = dict_df[dict_df["version"] == version].copy()
        # 构建 别名 → 标准名 的映射
        self.alias_map = {}
        for _, row in self.dict_df.iterrows():
            for alias in row["alias_list"].split(","):
                self.alias_map[alias.strip()] = row["standard_name"]
        # 标准值列表（用于模糊匹配）
        self.standard_names = self.dict_df["standard_name"].tolist()

    def standardize(self, raw_value):
        """标准化单个地区值"""
        if pd.isna(raw_value) or str(raw_value).strip() == "":
            return None
        raw = str(raw_value).strip()

        # 1. 精确匹配
        if raw in self.alias_map:
            return self.alias_map[raw]

        # 2. 模糊匹配（rapidfuzz，阈值 85）
        match = process.extractOne(
            raw, list(self.alias_map.keys()), scorer=fuzz.WRatio)
        if match and match[1] >= 85:
            return self.alias_map[match[0]]

        # 3. 匹配不到，返回原始值并标记
        return raw

    def standardize_series(self, series):
        """标准化整列"""
        return series.apply(self.standardize)


def classify_feedback_type(text, type_dict_df):
    """根据关键词匹配反馈类型"""
    if pd.isna(text) or str(text).strip() == "":
        return "其他"
    text = str(text)
    for _, row in type_dict_df.iterrows():
        keywords = row["alias_list"].split(",")
        for kw in keywords:
            if kw.strip() in text:
                return row["standard_type"]
    return "其他"


def standardize_all(df, region_dict_df, type_dict_df, version="v1.0"):
    """枚举标准化主流程"""
    # 地区标准化（假设反馈里带 region 字段，或从手机号归属地解析）
    if "region_raw" in df.columns:
        std = RegionStandardizer(region_dict_df, version)
        df["region_standard"] = std.standardize_series(df["region_raw"])
        # 统计匹配率
        matched = df["region_standard"].isin(
            region_dict_df["standard_name"]).sum()
        match_rate = matched / len(df) if len(df) > 0 else 0
        print(f"[Std] 地区匹配率: {match_rate:.2%}")
        if match_rate < 0.90:
            print("[Std] 警告：地区匹配率低于 90%，需补充字典")

    # 反馈类型分类
    df["feedback_type"] = df["feedback_text"].apply(
        lambda t: classify_feedback_type(t, type_dict_df))
    type_dist = df["feedback_type"].value_counts()
    print(f"[Std] 反馈类型分布:\n{type_dist}")

    df["dict_version"] = version
    return df


if __name__ == "__main__":
    # 示例验证
    region_dict = pd.DataFrame([
        {"standard_name": "北京市", "alias_list": "北京,北京市,BJ,Beijing,beijing",
         "version": "v1.0"},

    ])
```
