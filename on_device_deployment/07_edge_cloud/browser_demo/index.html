浏览器端推理接入骨架

真实推理请接入 WebLLM / Transformers.js / Chrome Prompt API。 本页演示选型提示、缓存策略与 API 形状，可直接用本地静态服务器打开。

何时用浏览器

  • 零安装试用 / 营销落地页
  • 数据不出浏览器的隐私演示
  • 轻量 1–2B 级助手

何时用原生

  • 要稳的后台常驻与 NPU
  • >2GB 模型或长会话 Agent
  • 语音全链路 / 相机强实时

缓存要点

  • Service Worker 缓存 WASM/模型分片
  • 首次加载提示进度与体积
  • Tab 内存通常 1–2GB 量级

伪代码：WebLLM 风格会话

// npm: @mlc-ai/web-llm
import { CreateMLCEngine } from "@mlc-ai/web-llm";

const engine = await CreateMLCEngine("Llama-3.2-1B-Instruct-q4f16_1", {
  initProgressCallback: (p) => console.log(p.text)
});

const reply = await engine.chat.completions.create({
  messages: [{ role: "user", content: "用一句话解释端侧部署" }],
  stream: false
});
console.log(reply.choices[0].message.content);
