# LLM 技术学习工作区

> 目的：把 LLM 时代**真正在生产里跑着**的技术，整理成可检索、可复习、可动手验证的笔记。
> 收录原则：优先「已被头部公司规模化使用」；纯论文、纯 demo 标注为「前沿」，不占主线。

## 怎么用

1. 先读 [`00-技术地图.md`](00-技术地图.md)，建立全局坐标——知道每个技术**在哪一层、解决哪种稀缺资源**。之后看到任何新名词，都先问一句：它属于哪一层？
2. 再按「主线」深潜，不要按名词表背。当前已完成：
   - [`01-缓存与上下文复用.md`](01-缓存与上下文复用.md) — 缓存六层模型、命中率工程 12 条、反模式清单
   - [`02-高命中率实战.md`](02-高命中率实战.md) — 命中率的四个乘数、PIC/EPIC、分层与池化、落地顺序
3. 名词卡住时查 [`99-术语表.md`](99-术语表.md)。

## 文档约定

每篇深潜文档保持同一骨架，方便横向对比、也方便你自己往里面加：

| 段落 | 必须回答的问题 |
|---|---|
| **问题** | 不做这件事会付出什么代价（尽量给数字） |
| **原理** | 最小必要机制；一张图 + 一段伪代码 |
| **工程** | 怎么开、怎么配、怎么度量 |
| **公司实践** | 谁在生产里用、用的什么形态 |
| **反模式** | 什么时候它会反噬 |
| **自测** | 3–5 题，能答上才算学会（答案折叠） |

## 技术地图速览

| # | 类别 | 一句话 |
|---|---|---|
| 1 | 推理引擎与内核 | 把 GPU 从「利用率 20%」榨到「70%」的底层功夫 |

| 10 | 评测、可观测与安全 | 非确定性系统的质量与安全兜底 |

## 一条自我检验标准

学完一个技术，如果你能回答下面三个问题，才算真的懂：

1. 它省的是**算力、显存、还是上下文**？
2. 它在什么规模下**不划算**？（所有技术都有拐点）
3. 上线后看**哪个指标**能判断它有没有生效？
