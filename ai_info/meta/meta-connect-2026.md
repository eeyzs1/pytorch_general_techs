# Meta Connect 2026:Muse 从聊天助手扩展为消费级 AI 系统（Meta Connect 2026: Everything We Announced）

- **检索日期**: 2026-09-29

## 核心观点

Muse 个人智能体发布仅 15 天后,Meta 在 Connect 2026(09-24)把它从聊天助手扩展为覆盖语音、视频、电脑控制、邮件、购物、工作应用、AI 眼镜与口袋设备的消费级 AI 系统。软件侧最大更新是 Muse Realtime Voice:支持更长的实时对话且 Agent 在后台继续干活,用户可以用文字描述定制 Muse 的声音;MSL 同步推出研究性的 [Muse Realtime Avatar](muse-realtime-avatar.md) 把语音对话变成实时视频角色。

能力扩展:经许可控制 Mac、获得专属 email 地址、更多第三方服务连接器;硬件侧预告口袋设备 Muse Charm,并延续 AI 眼镜与 VR 产品线(含 100g 级超轻头显)。市场验证:Muse 上线 12 天移动端下载量超过 ChatGPT 同期、登顶 App Store 榜单;Zuckerberg 现场表示"我们相信 Muse 会为你挣钱"。

## 关键发现 / 关键技术

### 1. Muse Realtime Voice 与 Avatar
- Realtime Voice 进入产品:长对话进行中 Agent 保持后台任务执行;声音可按用户文字描述定制。
- Realtime Avatar(研究层):参考图像→实时对话角色,870ms 首响、25fps,详见独立文章。

### 2. Agent 能力边界外扩
- Mac 控制(需用户许可)——个人 Agent 首次进入 Meta 生态外的桌面环境;
- 专属 email 地址:Agent 拥有可接收邮件的身份入口,配合既有"代发邮件/订行程/购物"能力形成闭环;
- 更多第三方连接器与购物整合。

### 3. 硬件矩阵
- Muse Charm:口袋设备形态预告,与"全天候 Muse Secure VM"架构呼应;
- AI 眼镜与 VR 更新(超轻头显 100g 级),眼镜成为 Muse 的常驻入口。

### 4. 采用数据
- 前 12 天移动下载量超 ChatGPT 发布同期,App Store 榜首;官方口径 Muse"人手一台 AI 虚拟机、全天候干活",并探索让 Muse 自主创收。

## 实践意义

对个人 Agent 赛道:Muse 两周内完成"发布→ Connect 全场景扩张"的节奏,把 OpenAI(Operator/ChatGPT Work)与 Anthropic(Cowork)的桌面 Agent 战争拉到消费硬件+社交分发维度——眼镜、口袋设备、Instagram 入口构成 30 亿日活级分发优势。专属 email 与 Mac 控制意味着 Agent 权限边界(凭据、授权、审计)将从手机 App 内走向整个数字生活,安全架构(参考 Muse 的 Secure VM + Sentinel 设计)成为竞争焦点。

## 跨厂商对比

- 与 [Muse 个人智能体](introducing-muse-personal-ai-agent.md) 及 [How We Built Safety Into Muse](security-and-safety-for-ai-agents-our-approach-with-muse.md) 构成连续叙事:09-08 发布并公开安全架构 → 09-24 Connect 全场景扩张——权限外扩速度与安全披露同步,是个人 Agent 治理的对照样本。
- 与 [Claude Cowork 与聊天合并](../anthropic/engineering/cowork-is-now-claude.md) 同向:Anthropic 把 Cowork 并入聊天做"一个 Claude",Meta 把 Muse 推向语音/形象/硬件全入口——通用 Agent 的"多入口统一"成为两家共同路线,分发渠道(社交+硬件 vs 桌面+API)是分化点。
