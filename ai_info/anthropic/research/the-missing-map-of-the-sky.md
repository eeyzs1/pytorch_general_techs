# 天空缺失的地图：首张完整紫外全天图（The missing map of the sky）

- **原文链接**: [The missing map of the sky](https://www.anthropic.com/research/the-missing-map-of-the-sky)
- **作者**: Brice Ménard（约翰霍普金斯大学天体物理学家 / Anthropic 研究者）
- **发布日期**: 2026-10-08
- **检索日期**: 2026-10-16

## 核心观点

霍普金斯天体物理学家 Ménard（现为 Anthropic 研究者）用 Claude Science 编排多 agent 团队，制作出史上第一张完整的紫外波段全天图：汇聚 GALEX/Swift/FIMS-SPEAR/TD-1 等全部公开 UV 巡天，统一标定、互校、合并，再用 inpainting + 多波段回归把约三分之一从未被观测的天空"预测"出来（误差约 10%，肉眼不可辨），最后叠加 Gaia 推断的 1 亿+ 恒星 UV 辐射。

文章的真正论点是优先级革命：这类"人人知道该做、但永远排不上日程"的基础资源建设，50 年来因耗时数周的像素级标定而无人认领；Claude 让"低优先级高价值"工作首次变得可负担——且不需要牺牲研究者的主线时间。

## 关键发现 / 关键技术

### 1. 为什么 50 年没有完整 UV 图
- UV 被臭氧层吸收，必须上天观测；GALEX（2003–2013）只覆盖约 2/3 天区，且刻意避开银河系恒星密集区以免损坏探测器
- 统计补全方法存在，但需要逐像素标定与反复分析数周——天文学家自然把它让位给"更紧迫"的研究

### 2. 多 agent 流水线
- agent 并行搜索/下载公开巡天 → 分时段自洽标定（重点处理亮星眩光）→ 跨仪器互校 + 统一坐标与分辨率 → 合并
- 缺口填充：用已观测的 2/3 天区学习 UV 亮度与可见光/红外/射电的关系，应用到无数据的 1/3；自检方法是把已知区域遮住再预测，多轮精化后误差约 10%
- 人类角色是验收：Ménard 偶然发现最暗视场残留 GALEX 单次观测的圆形脚印（大气余辉未除净）——agent 两轮自审都没抓住，人类一句话触发全部 38,000 次观测的重新标定

### 3. 协作节奏
- 十几个版本迭代，数天完成；人负责规划与审查，Claude 独立跑数小时计算
- 成品含"实测/预测"逐像素标记与不确定度图层，可作为教学与研究的正典图集

## 实践意义

对科研机构的启示：AI 的最大短期价值未必在攻坚诺奖级难题，而在解锁"积压清单"——每个领域都有这类被搁置的数据整合/标定/资源建设任务，现在可以系统性清账。工程上这篇是"多 agent + 人类验收"模式的干净样本：agent 自审有盲区（圆形脚印漏检），人类的抽查仍是质量闸门，但抽查成本已降到"看一眼图"的量级。地图本身（含不确定度标注）为"AI 生成科学产品如何诚实标注预测部分"提供了范本。
