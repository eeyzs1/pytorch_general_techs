# Agentic Coding and Persistent Returns to Expertise

- **原文链接**: [Agentic coding and persistent returns to expertise](https://www.anthropic.com/research/claude-code-expertise)
- **作者**: Anthropic Economic Research
- **发布日期**: 2026-06-16
- **检索日期**: 2026-06-29
- **标签**: #EconomicResearch #ClaudeCode #AgenticCoding #Expertise #DivisionOfLabor #KnowledgeWork

## 核心观点

基于对约 400,000 个 Claude Code 交互会话（来自约 235,000 人，2025 年 10 月至 2026 年 4 月）的隐私保护分析，Anthropic 报告：编码代理正在重塑知识工作，但"领域专长"而非"编码能力"是决定性因素。在典型会话中，**人做约 70% 的规划决策，Claude 做约 80% 的执行决策**——清晰的人机分工。

## 关键发现

### 1. 人机分工清晰
- 用户平均贡献 **70% 的规划决策**（"做什么"），但只贡献 **20% 的执行决策**（"怎么做"）
- 单次会话平均有约 4 个 turn（轮次），每个 turn Claude 平均执行约 10 个动作、有时超过 100 个
- 用户保留执行控制时，Claude 每 turn 约 8 个动作；Claude 接管规划时，每 turn 约 16 个动作

### 2. 领域专长放大代理效用
- 在专家会话中，每个 prompt 触发约 12 个 Claude 动作和 3,200 词输出
- 在新手会话中，每个 prompt 仅触发约 5 个动作和 600 词输出
- 这一差距在控制工作模式、任务价值、月份、职业、模型族后依然显著（每提升一级专长，动作数 +9%，输出 +13%）

### 3. 成功主要取决于专长而非编码能力
- 每个主要职业（会计、律师、研究人员、销售）在编码任务上的成功率与软件工程师几乎持平
- **专长用户成功率更高**——专家比中级用户更能从错误中恢复
- 但专家与中级的差距较小——熟练使用即可，无需顶级大师

### 4. 工作模式正在演变
- 修复 bug 的会话占比从 33% 降至 19%（-50%）
- 操作软件（部署、配置、监控）从 14% 升至 21%
- 写作和数据分析从约 10% 翻倍到约 20%
- 任务价值按 freelance 市场比价，**平均上升 27%**

### 5. 增长最快的非开发用户群
- 管理层、销售、法律是增长最快的非软件职业
- 编码代理用户人均周使用 **20 小时**

## 关键洞察

1. **领域专长不可替代**：编码代理放大的是"对要解决问题有深度理解"的人，而非"会写代码"的人
2. **决策权是关键劳动分工**：人决定"做什么"，代理决定"怎么做"——这一模式可能延伸到非编码知识工作
3. **工作向"运营"和"分析"迁移**：随着代理接手代码编写，用户更多使用 Claude Code 来部署、运行、分析数据、写非代码文档
4. **任务价值上升 = 工资上升的先兆**：任务价值与代理使用频率呈正相关，可能预示劳动力市场对"会用代理的专家"的需求扩大
