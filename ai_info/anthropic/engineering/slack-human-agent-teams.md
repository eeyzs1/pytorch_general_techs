## 核心观点

这是 Anthropic "构建人机团队"系列的第二篇，与 Slack 首席产品官 Jaime DeLanghe 对话，探讨企业如何把对话转化为机构知识。Slack 早在 AI 到来之前就思考"人机团队"——DeLanghe 从 2017 年加入 Slack 起就致力于把工作场所对话转化为可检索的机构知识，核心信念是：人们应该在开放的频道中工作，让对话、决策和进行中的工作在任何人可读可搜的地方展开。

她提出的核心命题是"The Work is the Conversation"（工作即对话）——当 AI Agent 加入 Slack 频道，它们不只是回答问题，而是与人类在同一知识空间协作，对话本身成为 Agent 的训练数据与知识来源。

## 关键发现 / 关键技术

### 1. 工作即对话（The Work is the Conversation）
- 开放的频道工作文化：对话、决策、工作进展都可读可搜
- 对话本身就是机构知识库
- Agent 加入频道后与人类共享同一知识空间

### 2. 人机团队的设计原则
- 人类与 Agent 在同一频道协作，而非隔离
- Agent 从对话中学习上下文，回答更有依据
- 透明度：所有协作都在可审计的开放空间

### 3. Slack 的实践
- CPO 视角的企业 AI 协作战略
- 搜索与机器学习背景塑造的方法论
- 从"对话"到"知识"的机构转化路径

### 4. 系列文章定位
- Anthropic"人机团队"系列第二篇
- 第一篇分享 Anthropic 内部多玩家 AI 协作经验
- 本文引入外部企业实践

## 实践意义

Slack 案例把"人机团队"从概念落到具体产品实践：频道是知识容器，对话是知识流，Agent 是知识协作方。对企业而言，"开放工作文化"是人机团队的前提——封闭的私聊环境无法让 Agent 学习上下文。这与 monday.com 的 agent-first 重构、Anthropic 内部的多玩家 AI 协作共同构成"企业 Agent 协作"的完整案例集。
