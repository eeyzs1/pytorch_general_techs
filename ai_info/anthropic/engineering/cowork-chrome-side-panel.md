# Claude Cowork 来到 Chrome 侧边栏（Claude Cowork comes to the Chrome side panel）

## 核心观点

Chrome 中的 Claude 侧边栏正式升级为 Claude Cowork 会话：在浏览器中给 Claude 一个任务，它可跨标签页工作，并在桌面、移动端与 Web 应用中延续同一对话。对话保存到历史记录，技能与连接器在浏览器中可用，一个标签页开始的任务可在 Claude 桌面/Web/移动应用完成。Max 与 Team 计划当日可用，Pro 用户数周内逐步开放。

Claude in Chrome 是让 Claude"看到当前页面并采取行动"的浏览器扩展——点击链接、输入文本、翻页、填表，使用既有登录状态。许多日常工具直接连接到 Claude，但内部仪表盘、遗留系统、供应商门户等没有；通过浏览器，Claude 可以在这些应用内工作。

## 关键发现 / 关键技术

### 1. 侧边栏 → Cowork 会话
- Chrome 侧边栏对话升级为完整 Cowork 会话
- 跨标签页工作能力
- 任务在浏览器中开始、在桌面/移动/Web 完成

### 2. 跨设备延续
- 对话保存到历史记录
- 桌面、Web、移动应用无缝衔接
- 一个任务跨设备完成

### 3. 浏览器内技能与连接器
- Skills 与 connectors 在浏览器中工作
- 扩展现有工具生态到浏览器场景
- 内部系统、遗留系统、供应商门户均可操作

### 4. 分阶段开放
- Max 与 Team 计划当日可用
- Pro 用户数周内逐步开放
- 与 Claude 桌面应用形态互补

## 实践意义

Claude Cowork 进 Chrome 填补了"浏览器内操作"的空白：许多企业应用没有 API 或连接器，只能通过浏览器访问。Cowork 让 Claude 在这些"封闭应用"内工作，扩展了 Agent 的可用范围。跨设备延续意味着"浏览器里发现任务、桌面端完成重活"成为可能，是 Claude 多端生态的关键一环。
