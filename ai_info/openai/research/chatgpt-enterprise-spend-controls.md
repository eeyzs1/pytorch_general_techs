## 核心观点

ChatGPT Enterprise 推出**新的使用分析**和**更细粒度的支出控制**——管理员可在 Global Admin Console 中查看 ChatGPT 和 Codex 的统一信用额度使用情况，按用户、产品、模型分解，识别高使用用户和异常模式。新增**默认额度 + 组级别额度 + 个人覆盖额度**三层控制。

## 关键功能

### 1. 信用额度使用分析（Global Admin Console）
- ChatGPT 和 Codex 信用额度统一视图
- 按**用户、产品、模型**分解
- 可识别：
  - 高使用用户和新兴模式
  - 有价值工作驱动的使用增长
  - 需要审查的异常模式
- 数据可通过**统一的 Cost API** 在自有系统中深度分析

### 2. 支出控制
- 之前：自定义角色的细粒度额度限制
- 现在：
  - 工作区**默认额度**
  - **特定组**额度
  - **个人覆盖额度**
- 员工可：
  - 查看自己的信用使用情况和预算
  - 需要时申请增加额度
  - 提供"在做什么"的上下文——帮助管理员决策

### 3. 客户案例
- **Zipline**：从 1 月起全公司采用 Codex；让 OpenAI 构建使用分析来发现/培训未采用者；保持支出可预测

## 关键洞察

1. **企业 AI 治理进入精细化阶段**——从"给所有人一个预算"到"按角色/个人定制"
2. **统一 ChatGPT + Codex 视图**——AI 使用不再是单产品管理
3. **Cost API 让企业集成自有系统**——避免管理员在多个工具间切换
4. **员工申请 + 上下文**——避免不必要的全员额度提升
5. **Zipline 案例显示采用率提升是关键 KPI**——不是单纯节省成本
