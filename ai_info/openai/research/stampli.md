# Stampli 用 ChatGPT Work 将上线工时削减 68%（Stampli cuts launch hours by 68% using ChatGPT Work）

## 核心观点

Stampli 是智能 procure-to-pay 平台（连接采购、应付账款、供应商管理、支付与员工支出），其 Deep Finance 产品把平台内流动的数据转化为面向 CFO 与业务负责人的支出情报。在固定时间线、设计资源与外部承包商均已另有所属的约束下，营销团队用 Codex 把产品上下文、会议纪要、决策与信息指南接入一个共享系统，将估算 243 小时的发布生产工作压缩到约 77 小时——节省约 166 小时，生产速度提升 3.16 倍（工时削减约 68%），并保留对一切客户面向内容的完整人工审查与最终批准。

Deep Finance 从原型演示到公开 GTM 发布与首个 shipped 产品仅用约六周。CEO Eyal Feldman 的评价："Codex 缩短了从客户需求、团队响应到真实使用学习之间的距离……它让我们从需求到可部署方案快了 10 倍。"

## 关键发现 / 关键技术

### 1. 六周从原型到发布：GTM 生产线
- Codex 把不断演进的产品决策转化为可审查资产：七篇博客系列、发布邮件、网络研讨会及其幻灯片、社交与付费创意、PR Newswire 新闻稿、产品页与销售赋能材料。
- 发布主打动画约 90% 的精细制作由 Codex 完成（探索、迭代与打包），承包商只收尾开场场景与最终格式。
- 工时账本：无 Codex 估算约 243 个建模活跃工时，实际约 77 小时，节省约 166 小时（3.16 倍提速）。

### 2. 日常化的系统与"第二大脑"
- 支撑发布的基础设施就是产品营销团队的日常系统：GPT 驱动的系统从产品系统与会议纪要汇集信息，自动保持帮助中心文章、演示材料与 one-pager 更新，替代此前采访 PM、读 Jira、翻 GitHub 与会议纪要的手工流程。
- 连接到"唯一事实源"的 agent 每周产出数百份网站与社交内容（产品营销总监 Melad Zahedi：此前每周只有两三份，产出放大 10 倍）。
- 决策支持：自动化的"第二大脑"帮员工准备连轴会议；一次高管会上，员工用 20 秒键入让 Codex 检索并分析跨 HubSpot 等系统的指标——FP&A 团队原本需要半天才能给出可信报告。

## 实践意义

Stampli 展示了营销职能从"内容工厂"到"AI 辅助 GTM 系统"的转变路径：关键不是单次发布的省时，而是把产品知识保持、内容生产与数据检索沉淀为可持续运转的自动化管线。243→77 小时的建模口径（活跃角色工时）也为营销团队量化 AI 回报提供了诚实的方法论——区分"AI 完成"与"人复核批准"，避免把人工审查环节计入节省。

对中型企业的启示与 ATV Big Air Tour 等 SMB 案例一致而规模更高：固定截止日期 + 资源被占用时，Codex/ChatGPT Work 组合是"六周做完原本一个季度工作"的主要杠杆，且人的角色上移到战略建议与最终把关。
