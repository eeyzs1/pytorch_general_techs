## 核心观点

MIT 工程量子系统组（EQuS）博士生 Beatriz Yankelevich 把 GPT-5.6 Sol 接入 Codex 并连接实验室软件，让 AI 直接操作超导量子比特实验：自主运行测量、分析结果并决定下一步。对未校准六比特芯片的标准测量序列，Sol 能在极少人工干预下完成——识别跃迁频率、校准控制与读出脉冲、测定量子信息保持时间。

这一工作流的解放效应是实打实的：agent 可通宵运行测量，研究者从手机上查看进展并按需转向，把时间投入到实验设计、结果解释与规划。局限同样清晰：信号弱或噪声大时，Sol 找参数更慢且需要资深研究者指导——明确定义的实验流程可自动化，含糊的物理解释仍属人类。

## 关键发现 / 关键技术

### 1. 为什么量子校准是 agent 的天然试验场
- 超导量子比特冷却至近绝对零度（稀释制冷机），芯片封装后研究者完全通过软件与之交互——天然适配 agent
- 校准是相互依赖的测量链：每步结果决定下一步（微波脉冲设计与校准、信号数字化分析、共振频率/T 相干时间测定），且量子比特属性会漂移、异常物理行为会导致不一致结果，需要自适应决策
- 实现方式：为 Codex 提供逐项测量的"技能"（如何运行与评估每个实验），Sol 依据技能与芯片设计目标选择测量参数、操作硬件、分析数据，然后精化测量或保存结果供后续使用

### 2. 实测表现与边界
- 信号清晰时：标准测量序列近乎自主完成（跃迁频率、脉冲校准、相干时间全链路）
- 信号弱/噪声大时：寻找合适参数耗时更长，有时需要资深研究者指导——"解释模糊物理结果"仍是当前 agent 的短板
- EQuS 现已常规用 agent 处理例行测量（每块标准芯片人工表征需数天）；新实验则给 agent 更窄的目标，同时利用其编写/修改/测试控制、分析与仿真代码的能力

### 3. 人机分工模式
- "多个 agent 同时处理不同问题，我把时间花在解读结果、设计实验、规划下一步、阅读与写作上"
- 已为测量、理论、芯片设计三部分工作搭建引导 agent 的基础设施
- 随时可从手机 check-in 并转向——监督是异步抽查而非全程盯守

## 实践意义

本文给出了"agent 接管实验室例行科学工作"的可复制模板：把领域操作封装为技能说明、让 agent 持有参数选择-运行-分析-精化的闭环、人类保留物理解释与实验设计。对实验科学团队，最有迁移价值的是其分层委托策略——明确定义的流程全自动化、模糊判断收窄为窄目标并要求人类复核。对 agent 工程师，这是一份"垂直领域 ACI"的实证：成功不依赖通用智能突破，而依赖测量技能的清晰封装与实验室软件的顺畅连接。
