## 核心观点

Atlassian 与 OpenAI 扩大战略合作伙伴关系：把前沿模型接入 Atlassian 体系承载的企业知识（Jira/Confluence 等产品多年沉淀的计划、协作与交付数据），让团队"计划、构建、交付工作"的全程获得智能体支持。Atlassian 官方博客以"Grounding Frontier Intelligence in Enterprise Context"（让前沿智能扎根企业上下文）定位此次合作——卖点不是模型本身，而是模型 + 企业真实工作上下文的组合。

## 关键发现 / 关键技术

### 1. 合作定位：知识接地（grounding）
- 前沿模型（GPT-6 系列）连接 Atlassian 的企业知识资产，把散落在工单、文档、项目计划里的组织记忆变成 Agent 可用的执行上下文。
- 目标场景覆盖团队工作全流程：规划（plan）、构建（build）、交付（deliver）。

### 2. 战略含义
- OpenAI 侧：继 AWS/Oracle/Dell/HP 多云分发之后，向"工作操作系统"层渗透——企业知识所在之处即 Agent 的部署面。
- Atlassian 侧：在 Copilot 类竞品压力下选择深度绑定前沿模型厂商，以数据与工作流优势换取智能层差异化。

## 实践意义

1. **企业知识的 Agent 化入口**：协作平台沉淀的结构化工作史（谁做过、怎么做的、结果如何）是长视野 Agent 最稀缺的训练与接地素材，此类合作预示"知识管理"与"Agent 运行时"合流。
2. **采购视角**：模型能力趋同后，与自有数据资产的连接深度成为企业选型的核心变量。

## 跨厂商对比

- 与 [OpenAI Frontier Models on AWS](openai-frontier-models-and-codex-are-now-available-on-aws.md) 对比：多云分发解决"在哪跑"，Atlassian 合作解决"knows what"——分发渠道与知识渠道两条战线同时扩张。
- 与 [Put Data to Work（ChatGPT Work Data agent）](put-data-to-work.md) 互补：Data agent 让 ChatGPT 内做 BI，Atlassian 合作让企业系统内长 Agent——同一"企业知识→行动"命题的两端实现。
