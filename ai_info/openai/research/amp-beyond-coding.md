## 核心观点

智能体公司 Amp 把 OpenAI 全家桶——GPT-6 Astra、Ultrafast 高速模式、GPT-Live-1 实时语音、Sign in with ChatGPT——组合用于"代码之外"的工作场景，展示前沿智能体的能力边界。案例价值在于产品组合的完整度：一个创业公司同时吃到 DevDay 发布的四层能力（最强推理、最快速度、实时语音、账号身份），是 OpenAI 平台化战略在创业生态的横截面。

## 关键发现 / 关键技术

### 1. 用到的 OpenAI 能力栈
| 能力 | 用途 |
|------|------|
| GPT-6 Astra | 前沿推理与执行 |
| Ultrafast | 高吞吐智能体任务（最高 6× API 速度） |
| GPT-Live-1 | 自然语音交互 |
| Sign in with ChatGPT | 用户身份与授权（不共享聊天记录与记忆） |

### 2. 信号：智能体创业的"平台租户"模式
- Amp 的差异化不靠自研模型，而在编排与场景层——DevDay 后 "Sign in with ChatGPT + 平台能力组合" 正成为新的创业默认栈。

## 实践意义

1. **选型清单**：四能力栈（推理/速度/语音/身份）可直接作为 2026 年构建通用智能体产品的采购 checklist。
2. **Sign in with ChatGPT 的冷启动价值**：免注册登录降低智能体产品获客摩擦，同时把信任边界交给 OpenAI 账号体系。
