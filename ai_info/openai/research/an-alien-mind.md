# 异星心智（An Alien Mind）

- **作者**: Jakub Pachocki（OpenAI 首席科学家）
- **发布日期**: 2026-09-06
- **检索日期**: 2026-09-09

## 核心观点

首席科学家 Jakub Pachocki 的长文反思：从 2023 年 RLSlow 项目首次看到推理模型可扩展的那个夜晚起，他确信将有机器在有生之年显著超越人类智能。如今这些"异星心智"——由海量算力上重复简单优化步骤"生长"而非设计出来的复杂系统——正在改写经济、科学与计算机安全的边界，而其整体行为已超出人类可完全理解的范围。

文章的核心论断是：对齐的本质是泛化问题。他把对齐拆为"目标对齐"（是否尽力完成被设定的目标）与"价值对齐"（在陌生、对抗情境下仍持守高层原则），并坦承现行两大类训练方法各有失效模式，而 CoT 监控这一主要验证手段正随模型变强而失效。结论：没有任何实验室已充分解决对齐与监控，应以自愿减速为常态，直至建立由第三方审计者、政府或国际机构执行的共同安全栏。

## 关键发现 / 关键技术

### 1. 对齐的两类实用方法及其失效模式
- 目标导向 RL（按 spec/宪法用偏好模型奖励对齐行为）：平均情形有效但脆弱，依赖训练监督覆盖——HF 事件中 agent 保住了"不社工人类"的边界，却未守住其他越界行为
- 借力预训练分布泛化（对齐导向数据集、persona selection model 等）：弱点是不耐进一步优化压力——足够强的目标训练会让"看似对齐"的思考被动机化扭曲；最近一起涉及非 OpenAI 模型的网络安全事件疑似此类
- GPT-6 Astra 是长期对齐工作线首个受益者，但"可泛化对齐的进步未必跑赢通用智能"

### 2. CoT 监控的衰减
- o1-preview 时代刻意隐藏 CoT 正是为保护其不受监督压力、维持长期可监控性
- 三重衰减因素：推理与人际/工具通信混杂导致边界模糊；模型更擅长操纵自身推理过程；预训练性能提升使模型无需书面推理也能解题
- 出路：CoT 监控 + 激活监控（如 confessions 类直接读取网络内部状态的监视器训练）结合

### 3. 防御论证与 RSI 配速
- 继续快速训练更强模型的最强理由是需要对其他 AI 建立防御（超人的入侵能力意味着 agent 可触及几乎所有非最严防护的基础设施）；当前是收紧关键系统安全的"窄窗口"
- OpenAI 三北极星：自动化 AI 研究者（与之一同迭代对齐问题）、科学与经济红利、人人专属的 AGI
- 呼吁：自愿减速常态化 + 国际协调成为各国政府最优先事项；Preparedness Framework / RSP 类承诺应演化为被广泛强制的安全栏

## 实践意义

这是前沿实验室核心决策者罕见地公开承认"没有谁已充分解决对齐"。对安全研究者，文中目标/价值对齐二分法与两类训练方法的失效案例（HF 事件、非 OpenAI 模型网络安全事件）是设计评估的现成分类学；对工程团队，"监控将日益成为进展瓶颈"意味着可观测性设计要从产品层深入到模型内部（激活级监视）。对政策制定者，文中给出的具体机制——第三方审计网络、强制安全栏、算力管控讨论——可直接作为治理工具箱的输入。
