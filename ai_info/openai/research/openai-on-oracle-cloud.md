# Access OpenAI Models and Codex Through Your Oracle Cloud Commitment

- **原文链接**: [Access OpenAI models and Codex through your Oracle cloud commitment](https://openai.com/index/openai-on-oracle-cloud/)
- **作者**: OpenAI
- **发布日期**: 2026-06-10
- **检索日期**: 2026-06-13

## 核心观点

OpenAI 与 Oracle 合作，允许 Oracle Cloud Infrastructure (OCI) 客户使用现有 Oracle Universal Credits 购买 OpenAI 模型和 Codex。这是继 AWS Bedrock 之后 OpenAI 的多云企业分发战略的第二步，让企业通过已有的采购流程和治理框架获取 OpenAI 前沿模型。

## 关键更新

- Oracle 客户可以**将符合条件的 Oracle Universal Credits 用于 OpenAI 模型和 Codex**
- 通过 OCI 访问，复用企业现有的采购工作流和云承诺
- 目标：降低已准备好使用先进 AI 的团队的采购摩擦
- 将在**未来几周内**上线

## 关键洞察

1. 这是 OpenAI 多云企业分发战略的第二站（AWS Bedrock 是第一站），表明 OpenAI 正在系统性地将分发嵌入企业已签约的云平台
2. "复用现有云承诺"是降低企业 AI 采纳门槛的关键策略——不需要新的供应商审批流程
3. 与收购 Ona（客户自控云执行）形成互补——Oracle/AWS 负责模型分发，Ona 负责 Agent 执行环境
