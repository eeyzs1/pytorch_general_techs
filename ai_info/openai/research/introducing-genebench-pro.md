## 核心观点

OpenAI 发布 **GeneBench-Pro**——面向研究级计算生物学的基准测试，考察 AI Agent 在模糊数据、迭代实验、判断决策（research taste）等高阶能力上的表现。区别于 GeneBench 的早期版本，GeneBench-Pro 覆盖 129 道专家级问题、10 个领域、21 个子领域，由 173+ 名 Ph.D. 撰写、453 名专家审查。GPT-5.6 Sol 在最高推理水平下达到 28.7% 通过率（开启 Pro 模式 31.5%），相比开发初期的 GPT-5（<5%）有质的飞跃。

### 3. 合成数据生成
- 每道题都**完整已知因果结构**，可直接模拟数据生成过程
- 调整每题复杂度，确保合理主观选择仍能产出可接受结果
- 通过消融实验验证"看似合理但错误"的分析会失败
- 通过详细 trace analysis 审计信息泄露与未预期解题路径

## 评估与评分

- **执行环境**：Agent 获得隔离工作区，含 prompt、数据文件、Python 科学计算栈、PLINK 2.0 等
- **评分方式**：直接对照已知真实目标做确定性评分——避免 rubric-based 评估的模型选择和冗长度影响
- **元数据**：每题附有预期分析结构、数据文件、多页案例研究、专家审查结果
- **开源与第三方**：在 Hugging Face 开源 10 道代表题 + 交互式网页；将向 Artificial Analysis 提供 50 题做独立第三方测评

## 结果与关键发现

### 1. 测试时计算扩展收益显著
- GPT-5.6 Sol 最低推理水平：**个位数通过率**
- GPT-5.6 Sol 最高推理水平：**通过率提升近 6 倍**，且仅用 GPT-5.2 约 2/3 的 tokens
- GPT-5.6 Sol（Pro 模式）达 **31.5%**

### 2. 专家级评估难度
- 评审估算每道题需人类专家 **20-40 小时** 完成
- 保守 $200/小时，单题人力成本 **数千美元**
- 当前 AI Agent 推理成本仅**数美元/题**
- 即使当前能力下，**部分自动化也能创造显著经济与科学价值**

### 3. 模型族对比
- 顶级 GPT 模型在"高阶科学推理 + 定量不确定性"上**显著领先**
- GPT-5.6 / GPT-5.5 与开源模型 GLM 5.2 的差距**远大于编码基准预期**
- 开源模型在通用推理上比编码专门化程度更低
- 竞争模型至多匹配对应发布时的 GPT 模型，多数明显落后

### 4. 主要失败模式
- 评审专家反馈：多数 Agent 失败在**数据问题谨慎度不足**
- 真实生物数据集常见不规范（ancestry swaps、C>T bias 等）
- 模型会"假装通过"而忽略 QC 步骤

## 跨厂商启示

- 与 [Introducing LifeSciBench](introducing-life-sci-bench.md) 互补：LifeSciBench 偏生命科学"完整研究工作流"评估（750 题、19,020 rubric），GeneBench-Pro 偏"判断决策"评估（129 题、合成数据）
- 区别于 [Paving the Way for Agents in Biology](../../anthropic/research/agents-in-biology.md)：Anthropic 强调"确定性执行层 + 数据基础设施瓶颈"，OpenAI GeneBench-Pro 强调"研究品味 + 高阶判断力"

## 局限与展望

- 当前 Agent 仍**不足以取代人类专家**完成独立分析
- 评审预计基准**可能在年底前饱和**
- 数据生成过程已尽最大努力，但仍可能存在未发现的解题捷径
- 后续将通过 Artificial Analysis 等独立机构持续监测模型进展
