# 支持泰国新一代 AI 初创企业（Supporting Thailand's next generation of AI startups）

## 核心观点

OpenAI 与泰国高等教育、科学、研究与创新部（MHESI）在曼谷宣布推出 OpenAI x MHESI AI Accelerator：一个为期八周的加速器，帮助泰国初创企业把有前景的原型变成可信赖、可实际部署的产品。首期十家初创公司横跨健康/福祉与教育两大领域，这也是 OpenAI 与泰国政府围绕支持本地初创企业的首个公私合作伙伴项目。

文章的核心论点是"演示易、产品难"：在医疗与教育这类高风险领域，可靠的产品需要严格测试、真实用户反馈、强护栏与可持续的商业模式。泰国已进入 ChatGPT 周活全球前 20，2026 年初以来 Codex 周活增长超 350 倍，加速器正是要把这股构建热情引向"可信落地"。

## 关键发现 / 关键技术

### 1. 计划结构与支持包
- 与国家创新局（NIA）、玛希隆大学、Techsauce 等伙伴共同交付
- 每家初创获得 2,000 美元 API 额度、OpenAI 一对一技术指导、最新前沿模型访问与全程专属导师
- 每周课程覆盖产品设计、工程、自动化测试、评估、负责任 AI、隐私与安全、成本管理、增长与融资；每队设定产品/试点/评估/商业化里程碑，11 月在曼谷举行 Demo Day 收官

### 2. 首期学员与背景数据
- 十家初创：CARIVA、Wello Food、Dietz、Precisionize、FitSloth（医疗与健康方向）；Curico、insKru、Floaino、EasyKids Robotics、Globish（教育方向）
- 部分团队来自今年早些时候的 AIAT × OpenAI Codex Hackathon Bangkok
- 泰国位居 ChatGPT 周活全球前 20；Codex 周活自 2026 年初以来增长超 350 倍，同样进入全球前 20

### 3. 从原型到部署的样例
- CARIVA：医院电话线多语言语音代理，可用患者偏好语言应答预约等常规请求并识别急诊来电；加速器期间将与 OpenAI 合作打磨实时语音模型的评估方法与引导策略，目标是在试点医院真实呼叫流中部署首个能力
- Curico：面向儿童、家庭与教育者的 AI 学习工具；目标是进入曼谷 200+ 托育中心试点、通过科普教学促进所的工作坊培训 200+ 教师、在朱拉隆功大学试点 AI 辅助评分、家庭学习平台月活破 1,000

## 实践意义

对政府与创新机构而言，这是一个可复制的"部委 + 厂商 + 大学 + 孵化网络"共建模板：MHESI 出政策与科研网络、NIA 连接资金与增长生态、玛希隆大学出学术导师、OpenAI 出模型与工程方法。对早期初创而言，其价值不在额度而在"评估方法、护栏与部署里程碑"的工程纪律——这正是从演示走向产品的最短板。

## 跨厂商对比

- 与 [ChatGPT 小企业计划](introducing-chatgpt-small-business-program.md) 对比：小企业计划面向使用者的普惠补贴，本篇面向构建者的深度孵化，是 OpenAI"消费侧普惠 + 供给侧深耕"的两翼。
- 与 [OpenAI 合作伙伴网络](introducing-openai-partner-network.md) 互补：伙伴网络把成熟服务商组织起来服务企业客户，本篇在泰国本地培育未来的产品与服务供给，长短期互补。
