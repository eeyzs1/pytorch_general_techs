## 核心观点

OpenAI 发布 Codex 经济影响论文，基于对个体、组织、OpenAI 内部三类用户群的使用数据分析。**Codex 已成为 OpenAI 内部每个部门（不仅是工程）的主要 AI 工具——平均输出 token 占比 85%+，占总 token 99.8%**。**80.6% 的个人用户提交了估计超过 30 分钟人类工作的 Codex 请求**。非开发者用户增速超过开发者（个体 137×、组织 189×、OpenAI 内部 12×）。

## 关键数据

### 1. 三类用户的 Codex 渗透率（截至 2026 年 6 月）
- OpenAI 内部：28 天活跃用户中 **97.9%** 用 Codex
- 组织用户：**17.3%**
- 个体用户：**0.7%**
- 输出 token 占比：OpenAI 内部 **99.8%** / 组织 63.3% / 个体 16.5%

### 2. 工作时长分布（个体用户，2026 年 5 月）
- 超过 30 分钟人类工作：**80.6%** 用户提交过
- 超过 1 小时：**70.2%**
- 超过 4 小时：（未给出具体数）
- 超过 8 小时：**25.6%**

### 3. 用户行为演变（OpenAI 内部）
- 工程：最早采用，2025 年 12 月平均工程师 50%+ token 在 Codex
- 法务、财务、招聘：2026 年 4 月成为主力，平均输出 85%+ token 在 Codex
- 当前：平均工程师 99% 输出 token 来自 Codex
- 用量增长（2026-06 vs 2025-11）：
  - 研究：56 倍
  - 客户支持：32 倍
  - 工程：27 倍
  - 法务：13 倍

### 4. 非开发者增长（2025-08 至今）
- 个体：137 倍
- 组织：189 倍
- OpenAI 内部：12 倍

### 5. 最重度用户
- OpenAI 内部日活用户的 99 百分位：**每天 60+ 小时的 Codex Agent turn**（并行多个 Agent）

### 6. 跨职能工作流
- 工程师：72% 输出用于"工程/编码"
- 数据科学/研究：51% 编码，30% 知识工作
- 财务/业务运营：34% 知识工作，31% 编码，16% 财务分析
- 产品/营销/运营：51% 知识工作，25% 编码

## 关键洞察

1. **Agent = 长视野任务的主力**——平均用户每月提交多个 1 小时+ 任务
2. **非工程部门加速采用**——法务、招聘、财务的过渡更快
3. **跨职能"代码民主化"**——业务用户 25%+ 工作在编码（以前完全靠工程师）
4. **日 60+ 小时 Agent turn**——单一用户的并行 Agent 编排能力极强
5. **个人 vs 组织 vs 企业鸿沟**——个体 0.7% 渗透率 vs 组织 17.3%，仍是大市场机会
