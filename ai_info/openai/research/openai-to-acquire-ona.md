# OpenAI to Acquire Ona

- **原文链接**: [OpenAI to acquire Ona](https://openai.com/index/openai-to-acquire-ona/)
- **作者**: OpenAI
- **发布日期**: 2026-06-11
- **检索日期**: 2026-06-13
- **标签**: #收购 #Ona #Codex #云基础设施 #企业安全 #持久化Agent

## 核心观点

OpenAI 宣布收购 Ona（后更名为 Ona），将其安全云执行和编排技术整合进 Codex 生态。此次收购的核心目标是让 Agent 在用户关闭笔记本电脑后仍能在客户自有的云环境中持续工作，将 Codex 从"会话绑定"扩展到"持久化生产工作流"。

## 关键更新

### 收购动因
- Codex 每周用户已超 **500 万**，较年初增长 **400%**
- Codex 最有价值的工作正在从"分钟级"扩展到"小时/天级"
- 用户需要能委托更复杂任务，不必一直守着发起任务的机器

### Ona 带来的核心能力
- **持久云环境**：Agent 可在客户自有云环境中持续运行，即使本地设备离线
- **客户控制执行模型**：Agent 运行在客户自己的云环境，OpenAI 提供智能和编排
- **企业级安全治理**：客户控制 Agent 运行位置、访问范围、凭证范围、活动日志、审查流程

### 企业价值
- Ona 已帮助 200 万开发者在安全、可复现的云环境中工作
- 多个共享客户已在使用
- 让企业能以"符合自身安全标准"的方式部署 Codex，同时不失智能化能力

## 关键洞察

1. 收购标志着 Codex 从"本地桌面 Agent"向"企业云 Agent 平台"的关键转变
2. "客户控制执行模型"解决了企业对 Agent 数据安全和合规的核心顾虑——Agent 在"你的云"而非"OpenAI 的云"运行
3. 持久化 Agent 是 Agent 从"实验"走向"生产"的前提条件——尚未完成的长时间工作不能依赖用户保持在线
4. 与之前的 Dell 合作（本地部署）形成互补——Ona 解决了"客户云"场景，Dell 解决了"本地"场景
