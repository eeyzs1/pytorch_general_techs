# 智谱 2026 半年度业绩会：GLM-5.x 靠后训练迭代，GLM-6.0 瞄准"自进化"

- **原文链接**: [智谱下一代基座模型已在推进，GLM-6.0瞄准"自进化"](http://www.nbd.com.cn/articles/2026-09-03/4571926.html)
- **作者**: 每日经济新闻（记者 可杨，编辑 杜宇）
- **发布日期**: 2026-09-03
- **检索日期**: 2026-09-09
- **标签**: #智谱 #财报 #GLM-6 #后训练 #国产芯片 #Scaling

## 核心观点

智谱（HK02513）2026 上半年营收 9.54 亿元（同比 +399.7%），其中开放平台及 API 业务收入 8.25 亿元（+2735.7%）、占总收入 86.5%；研发投入 21.31 亿元（+33.6%），期内亏损 20.72 亿元、同比收窄。业绩会回应了市场对"过度依赖后训练"的质疑：GLM-5.x 系列共用 2026 年 1 月完成的约 7450 亿参数基座，是结合数据、算力与各训练阶段边际收益的主动选择。

下一代基座 GLM-6.0 已在推进，方向包括更大的有效规模、更长原生上下文、原生多模态统一建模与"自进化"；算力侧已实现 10 万级国产芯片规模化推理，单位 Token 推理成本较年初下降 80%。（本文为业绩沟通会媒体披露，非官方公告。）

## 关键发现 / 关键技术

### 1. 财务结构：API 主导的增长
- 营收 9.54 亿元（+399.7%）；开放平台及 API 收入 8.25 亿元（+2735.7%），占比 86.5%（去年同期仅 15.2%）
- 企业级通用大模型业务收入 6704 万元，同比下滑 54.6%
- 研发投入 21.31 亿元（+33.6%）；亏损 20.72 亿元，同比收窄

### 2. "Scaling deep while scaling up" 训练路线
- GLM-5 基座约 745B 参数，2026 年 1 月完成训练，规划使用半年以上；GLM-5.1/5.2/5.3 的中训练、后训练与任务环境安排均提前规划
- GLM-5.3 与 GLM-5.2 同架构、同总参 / 同激活参，差异来自后训练规模：扩大长程任务环境与强化学习训练量，部分任务由传统编程扩展至更长周期工程任务
- 自建真实场景编程评测下，GLM-5.3 端到端完成率较 GLM-5.2 提升超 50%，公司判断该曲线尚未见顶
- 唐杰：国内大模型训练数据规模一般在 30–50 万亿 Token，单纯扩大基础参数收益有限；中训练与后训练均未把参数规模上限"打满"

### 3. 能力演进：Chat → Coding → Agent → Cowork → Autonomous AI
- Coding→Agent 的核心是长程规划与错误恢复；Agent→Cowork 要求输出达到可供专业人员复核的标准；目前处于 Coding 向 Agent、Cowork 扩展阶段
- 代码任务结果易验证（可运行、测试通过、漏洞修复），适合训练任务拆解、工具调用、错误恢复与长程执行
- 自 GLM-5.2 起联合多家国内安全团队，在真实代码中发现经筛选去重的漏洞 2436 个（中高危 1097 个），覆盖 269 个项目

### 4. GLM-6.0 方向与国产算力
- 下一代基座方向：更大的有效规模、更长原生上下文、原生多模态统一建模；扩大基座规模同时对激活参数做管控，避免推理速度下滑与成本上升
- "全自训练"理念：模型参与数据生成、训练环境搭建与基础设施优化；已尝试模型自我对弈生成数据、其他模型评审验证、筛选后投入训练
- 唐杰将 GLM-6.0 的关键挑战概括为"自进化"：模型能自己判断什么时候停止、什么时候纠正，而非简单把模型做大
- 10 万级国产芯片规模化推理，单位 Token 推理成本较年初下降 80%；GLM-5.3-Flash 是首款超大规模真实流量下全面依托国产芯片集群的模型，端到端服务性能较同硬件初始基线提升 3 倍

## 实践意义

这是少见的厂商完整公开"基座冻结 + 后训练迭代"决策逻辑的场合：在数据量（30–50 万亿 token）与算力约束下，把资源投向边际收益更高的后训练、强化学习与任务环境，而非堆参数。对模型团队而言，GLM-5.2→5.3 同参数、端到端完成率 +50% 是"后训练红利"的量化证据；对行业观察者而言，API 占比 86.5% 与单位推理成本半年降 80% 说明国产模型厂商的规模效应已在财务报表兑现。
