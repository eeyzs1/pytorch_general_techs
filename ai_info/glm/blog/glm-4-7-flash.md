# GLM-4.7-Flash:开源免费(GLM-4.7-Flash: Open Source and Free)

- **原文链接**: [GLM-4.7-Flash: Open Source and Free](https://www.zhipuai.cn/zh/research/148)
- **作者**: 智谱 GLM 团队
- **发布日期**: 2026-01-19
- **检索日期**: 2026-09-29
- **标签**: #GLM-4.7-Flash #智谱 #开源模型 #混合思考 #免费API #小模型

## 核心观点

GLM-4.7-Flash 是智谱开源免费的混合思考(hybrid thinking)模型,30B 总参数 / 3B 激活,在 SWE-bench Verified 与 τ²-Bench 综合表现上超过 gpt-oss-20b 与 Qwen3-30B-A3B-Thinking,成为同量级开源模型的新基准点。

它直接替代 GLM-4.5-Flash:旧模型于 1 月 30 日下线,调用自动路由到新模型。API 层面免费调用,权重同步在 Hugging Face 与魔搭开源——"免费 API + 开源权重"的双开放组合,明显是在为 GLM-5 系列蓄水生态。

## 关键发现 / 关键技术

### 1. 架构与定位

混合思考让成本随任务难度自适应,而不是一刀切地全量推理。

- 混合思考模型:按需切换思考/直答模式
- 30B 总参数 / 3B 激活,MoE 稀疏激活控制推理成本
- 思考预算可按任务复杂度动态分配

### 2. 基准表现

两个基准分别锚定编程与工具使用,共同指向"编程 + Agent"双能力定位。

- SWE-bench Verified:综合超过 gpt-oss-20b、Qwen3-30B-A3B-Thinking
- τ²-Bench(工具使用 Agent 基准):同量级领先
- 与参数量相近的开源对手全面对位竞争
- 30B 总参 / 3B 激活下取得,性价比是核心卖点

### 3. 替代与迁移

升级而非并行,避免社区碎片化维护两代 Flash。

- 替代 GLM-4.5-Flash,旧模型 1 月 30 日下线
- 存量 API 调用自动路由至 GLM-4.7-Flash,用户零改动迁移
- 下线时间距发布约 11 天,迁移窗口紧凑
- 自动路由意味着调用方无需改一行代码即可获得能力升级

### 4. 开放策略

- API 免费调用
- Hugging Face 与魔搭(ModelScope)双平台开源权重
- 免费服务 + 可私有化权重,分别覆盖尝鲜与生产两类用户

### 5. 生态卡位

- 发布时点先于 GLM-5 开源,为旗舰生态预热
- Flash 系列承担智谱"开发者入口"角色
- 免费层把试用流量沉淀为平台心智

### 6. 适用边界

- 3B 激活适合高频调用层:路由、意图识别、轻量工具调用
- 复杂难题仍应路由到旗舰模型,分层调度是成本最优解

### 7. 在智谱产品矩阵中的位置

- Flash(免费小模型)→ Turbo(场景增强)→ GLM-5.x(旗舰)的分层清晰
- 免费层筛选出高价值用户,再向上迁移到付费旗舰
- 对开发者:同一套 API 兼容全家桶,切换成本接近零

### 8. 混合思考的工程红利

- 简单查询走直答路径,节省思考 token 开销
- 复杂问题自动进入思考模式,不牺牲质量
- 对 Agent 高频调用场景,思考预算的动态分配直接影响成本

## 实践意义

GLM-4.7-Flash 把"能写代码、会调工具的混合思考模型"变成免费基础设施:3B 激活意味着单卡即可高并发部署,适合作为 Agent 系统中的高频调用层,把昂贵旗舰调用留给难题。对已在 GLM-4.5-Flash 上的存量用户,自动路由保证了无痛升级;对新用户,免费 API 是验证国产小模型 Agent 能力的最低成本入口。混合思考特性也让它在"简单查询不浪费算力、复杂问题不省思考"的自适应成本控制上具备独特优势。

## 跨厂商对比

- 与 [Gemma 4](../../google/deepmind/gemma-4.md) 对比:同为"开源小模型 + 免费可用"路线,Gemma 4 依托 Google 的多模态生态,GLM-4.7-Flash 以混合思考 + 工具调用基准(τ²-Bench)见长,分别代表海外与国产小模型的重点取向
- 与 [GLM-5.3-Flash](glm-5-3-flash.md) 对照:4.7-Flash(30B/3B)与 5.3-Flash 构成智谱 Flash 家族的迭代序列,免费策略一脉相承
- 与 [GLM-OCR:SOTA 复杂文档解析](glm-ocr.md) 互补:同为小体量开源模型,一个做通用推理,一个做文档解析专用
