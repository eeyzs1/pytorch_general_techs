# GLM-ASR-Nano:高鲁棒性语音识别(GLM-ASR-Nano: Robust Speech Recognition)

- **原文链接**: [GLM-ASR-Nano: Robust Speech Recognition](https://www.zhipuai.cn/zh/research/149)
- **作者**: 智谱 GLM 团队
- **发布日期**: 2025-12-09
- **检索日期**: 2026-09-29
- **标签**: #GLM-ASR-Nano #智谱 #语音识别 #鲁棒性 #方言 #热词

## 核心观点

GLM-ASR-Nano 是智谱的语音识别模型,仅 1.5B 参数(Whisper V3 编码器不计入),却在开源模型中取得最低平均错误率 4.10(Whisper V3 为 6.93)——小体量 + 高鲁棒性的组合,瞄准的是真实世界的"不完美语音"而非干净测试集。

其鲁棒性设计直击中文场景痛点:方言自然识别不强制转写为普通话、中英同句混说、耳语音量、嘈杂环境、自定义热词,支持 17 种语言。'智谱 AI 输入法'成为其首个生产级部署,验证了在 C 端高频交互场景的可用性。

## 关键发现 / 关键技术

### 1. 体量与精度

以显著更小的体量反超标杆开源 ASR。

- 1.5B 参数(Whisper V3 编码器不计入参数统计)
- 开源模型最低平均错误率:4.10
- 对比 Whisper V3:6.93
- 复用成熟编码器 + 自研解码侧,兼顾效果与体量

### 2. 真实场景鲁棒性

鲁棒性覆盖"音量、噪声、口音、语种混合"四个维度。

- 方言自然识别,不强制转写为普通话
- 中英同句混说(码切换)识别
- 耳语音量(低声语音)与嘈杂环境
- 每一项都是干净测试集测不出、真实用户天天遇到的场景

### 3. 自定义热词

- 人名、术语可按需注入
- 解决企业术语、客户姓名这类传统 ASR 的老大难
- 无需重训练即可适配垂直词表
- 热词机制让同一个基座适配不同行业的专有词汇

### 4. 语言覆盖

- 支持 17 种语言
- 多语与方言能力并存,面向国内真实语言生态
- 中英同句混说是国内办公场景的常态而非例外

### 5. 生产落地

- '智谱 AI 输入法'为首个生产级部署
- 输入法场景要求低延迟 + 高并发,验证了模型效率
- C 端部署倒逼的工程指标,比学术基准更能说明可用性

### 6. 部署形态

- 1.5B 体量适合端侧与私有化部署
- 数据不出域:合规敏感场景(客服、医疗、会议)的关键需求
- 自定义热词在私有化部署中可按业务域独立维护

### 7. 与 TTS 的成对设计

- ASR(12-09)与 TTS(12-10)相隔一天发布
- 语音输入 + 语音输出构成完整交互闭环
- 两者的私有化能力对齐,方便整体落地

## 实践意义

GLM-ASR-Nano 把 ASR 的竞争从"基准分数"拉回"真实可用性":方言不强制转普通话对粤语、吴语等用户是体验级差异;自定义热词解决了企业术语、客户人名这类传统 ASR 的老大难。1.5B 的体量适合端侧与私有化部署,'智谱 AI 输入法'的生产验证说明其延迟与并发指标已达 C 端要求。对做会议转写、客服质检、输入法的团队,这是开源 ASR 的新默认选项——平均错误率从 Whisper V3 的 6.93 降到 4.10,在质检与转写场景是显著的运营成本差异。
