# 智谱上线并开源 GLM-5.3-Flash：原生多模态 + 10 万张国产芯片承载线上流量

## 核心观点

8 月 26 日，智谱上线并开源 GLM-5.3-Flash（320B 总参 / A18B 激活），这是 GLM-5 系列的首个原生多模态模型，支持文本、图像、视频输入与 100 万 token 上下文；全部线上流量由 10 万张国产芯片承载。

发布前，该模型以匿名身份在 OpenRouter、OpenCode 两大海外平台测试，迅速登顶并刷新双平台历史纪录，Token 调用量高达 62T；揭晓后跃居 OpenRouter 榜首，使用量超过 DeepSeek 一倍以上。AA 综合智能指数 57 分、进入全球前沿区间，限时折扣价为 GLM-5.3 的 1/20。（官方研究列表 zhipuai.cn/zh/research 已确认 2026/08/26 发布条目"GLM-5.3-Flash：前沿智能进入普惠时代"；细节以媒体通稿与官方文档交叉核验。）

## 关键发现 / 关键技术

### 1. 原生多模态 + 百万上下文 + 稀疏激活
- GLM-5 系列首个原生多模态模型：输入支持文本 / 图像 / 视频 / 文件，输出为纯文本
- 100 万 token 上下文窗口、最大输出 128K
- 320B 总参数、A18B（约 180 亿）激活的 MoE 配置；首个采用稀疏注意力 + 线性注意力混合架构的开源前沿模型——相比 GLM-5.3，注意力计算量降低 3.01 倍、KV 缓存降低 4.44 倍
- 视觉能力原生融入 Coding 循环：模型主动观察界面、渲染结果与交互反馈并持续改进，在代码、浏览器与图形界面之间协同完成任务
- API 细节：`thinking.type` 仅支持 `enabled`（思考不可关闭）；推荐 `temperature: 1`、`top_p: 0.95`、`reasoning_effort: max`

### 2. "Ox Alpha" 匿名实测与登顶
- 正式发布前以匿名身份在 OpenRouter、OpenCode 登顶，刷新双平台历史纪录，Token 调用量 62T
- 揭晓后跃居 OpenRouter 排行榜首位，使用量超过 DeepSeek 一倍以上
- 匿名公开实测成为规避品牌偏见、以真实用量验证能力的新发布范式

### 3. 国产芯片承载全部线上流量
- 全部线上流量由 10 万张国产芯片承载（媒体披露口径）
- 相关产业链报道显示摩尔线程完成 Day-0 适配（IT 之家相关报道）

### 4. 能力定位与定价
- AA 综合智能指数 57 分，进入全球前沿模型能力区间
- 适合代码生成、代码理解、问题修复等代码任务；Office 与文档类任务、金融与法律等专业任务亦有显著提升
- 限时折扣价为 GLM-5.3 的 1/20，以极低门槛扩大开发者生态

## 实践意义

GLM-5.3-Flash 把"原生多模态 + 1M 上下文 + 开源 + 国产芯片推理"打包进一个低价模型，对长文档理解、多媒体 Agent 应用是当前性价比最高的选择之一。Ox Alpha 的匿名登顶路径说明海外开发者平台（OpenRouter / OpenCode）已成为国产模型的"能力公测场"，真实调用量比榜单更能说明问题；而 10 万张国产芯片承载全部线上流量，标志国产算力栈在超大规模真实流量下的可用性得到验证。

## 跨厂商对比

- 与 [GLM-5.3](glm-5-3.md) 对比：GLM-5.3（743B）主打编程与网络安全、AA 指数 60 分；GLM-5.3-Flash（320B-A18B）是系列的原生多模态经济版，AA 57 分、限时折扣价仅为其 1/20，两者构成"旗舰 + 高性价比多模态"双层产品线
- 与 [State of Open Models Summer 2026](../../huggingface/blog/state-of-open-models-summer-2026.md) 互补：HF 的开源模型综述描绘开源逼近闭源的整体趋势，GLM-5.3-Flash 以"开源 + 匿名实测登顶 OpenRouter + 国产芯片推理"提供 2026 年夏末的最新数据点
