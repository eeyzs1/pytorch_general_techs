# 智谱完成 50 亿美元再融资,年末 ARR 指引上调至 30 亿美元(Zhipu $5B Refinancing, ARR Guidance Raised to $3B)

- **原文链接**: [智谱完成50亿美元再融资 年末ARR指引上调至30亿美元](https://stcn.com/article/detail/4187296.html)
- **作者**: 证券时报
- **发布日期**: 2026-09-16
- **检索日期**: 2026-09-29
- **标签**: #智谱 #再融资 #ARR #算力扩容 #MaaS #商业化

## 核心观点

9 月 16 日,智谱宣布以"小股大债"方式完成 50 亿美元再融资(7 月已先落地 40 亿美元),资金全部投向算力扩容。公司同时上调业绩指引:当前全业务 ARR 18 亿美元,年末目标由 24 亿美元上调至 30 亿美元;指引公布当日股价盘中上涨 7%。

融资与指引背后是供不应求:2 月 GLM-5 发布后调用量增长 10 倍、自有算力耗尽,被迫停售 Coding Plan,7 月扩容后才恢复销售。收入侧新增长点包括与国内外头部云厂商签订的收入分成协议,以及开源模型海外托管 API 收入自 10 月起确认。

"小股大债"的结构含义同样关键:以债务而非股权稀释完成融资,偿付能力直接押注算力扩容后的收入兑现——18 亿美元 ARR 与 30 亿美元年末指引由此成为这场融资的信用背书。

## 关键发现 / 关键技术

### 1. 融资结构:小股大债、全部投算力
- 以"小股大债"完成 50 亿美元再融资;7 月已先获 40 亿美元
- 资金全部投向算力扩容,对应 10 万级国产芯片集群的持续扩张与后续推理供给
- 债务为主的结构保留了股权层面空间,偿付压力与算力变现的现金流入直接绑定

### 2. 供需拐点:调用量 10 倍与 Coding Plan 停售
- 2 月 GLM-5 发布后调用量增长 10 倍,自有算力耗尽
- 被迫停售 GLM Coding Plan;7 月算力扩容后恢复销售
- 教训明确:模型热度直接转化为算力缺口,扩容从"可选项"变为"收入的前置条件"
- 该事件与年内多次 API 提价共同说明:供给约束而非需求不足是当前主要矛盾(见 [GLM-5.3-FlashX 发布](glm-5-3-flashx.md))

### 3. 收入结构:云商分成 + 海外托管 API
- 与国内外头部云厂商签订收入分成协议,借助云商渠道放大调用量
- 开源模型海外托管 API 收入自 10 月起确认——开源生态从获客手段升级为可确认的海外收入通道
- 对开源商业模式的参照意义:国内开源模型首次规模化落地"第三方托管、按调用分成"的变现形态

### 4. ARR 与指引
- 当前全业务 ARR 18 亿美元
- 年末指引由 24 亿美元上调至 30 亿美元,上调幅度 +25%
- 由 18 亿到 30 亿意味着四季度需净新增约 12 亿美元 ARR,隐含增速显著高于上半年节奏
- 指引公布当日股价盘中 +7%

## 实践意义

"算力耗尽被迫停售"与"融资全部投算力"构成了比 ARR 更真实的供需信号:需求(调用量 10 倍)跑在供给(国产芯片集群扩张)前面,扩容进度直接决定收入天花板。

收入结构上,"云商收入分成 + 开源模型海外托管 API 确认收入"标志智谱从 MaaS 直销走向生态分成,开源开始直接贡献海外收入。对同行,智谱与 DeepSeek 在同一季度先后以指引上调与调价确认"低价换规模"阶段结束,商业模式向算力约束下的供需定价回归。

## 跨厂商对比

- 与 [智谱 2026 半年度业绩会](zhipu-h1-2026-earnings-glm-6.md) 对比:构成业绩连续性——中报营收 9.54 亿元(+399.7%)、API 占比 86.5%、单位推理成本较年初 -80%,到 9 月全业务 ARR 18 亿美元、年末指引 30 亿,增长叙事从"收入同比"切换到"ARR 指引"
- 与 [GLM Coding Plan 定价修订](glm-coding-plan-pricing-revision.md) 对比:Coding Plan 的定价与停售-恢复波动,本质都是算力供给约束在产品端的投影,本次融资即为此解绑
- 与 [DeepSeek-V4-Pro GA 与 API 调价](../../deepseek/news/deepseek-api-price-adjustment-2026-08.md) 对比:DeepSeek 用最高 1100% 的涨价宣告商业化转折,智谱用 50 亿美元债务融资 + ARR 指引上调 25% 表达同一判断——头部厂商集体告别烧钱换量
- 与 [GLM-5.3-FlashX 发布](glm-5-3-flashx.md) 对比:本轮融资投向的算力是 FlashX 提速与提价的物理前提,"资本开支→推理性能→定价能力"链条就此闭环
