# 智谱联合华为开源国产芯片训练的 GLM-Image(Zhipu and Huawei Open-Source GLM-Image, Trained on Domestic Chips)

- **原文链接**: [Zhipu and Huawei Open-Source GLM-Image, Trained on Domestic Chips](https://www.zhipuai.cn/zh/research/158)
- **作者**: 智谱 AI、华为
- **发布日期**: 2026-01-13
- **检索日期**: 2026-09-29
- **标签**: #GLM-Image #智谱 #华为 #昇腾 #MindSpore #文生图 #国产算力

## 核心观点

GLM-Image 是智谱联合华为开源的文生图模型,最大意义不在画质而在训练栈:全程在昇腾 Atlas 800T A2 + 昇思 MindSpore 上完成,证明国产算力 + 国产框架可以承载工业级图像生成模型的全流程训练,打通"国产芯片-国产框架-开源模型"的完整链条。

架构上采用"自回归 9B + 7B DiT 扩散解码器 + Glyph Encoder"的混合设计,在中英文字渲染上达到开源第一:CVTG-2K Word Accuracy 0.9116,LongText-Bench 中文 0.979(尤擅汉字)。支持 1024² 至 2048² 任意比例生成,API 定价 0.1 元/图,模型开源。

## 关键发现 / 关键技术

### 1. 国产训练栈全流程验证

全流程(而非部分阶段)落在国产栈上,是本发布最大的信号意义。

- 训练硬件:昇腾 Atlas 800T A2
- 训练框架:昇思 MindSpore
- 全流程在国产栈上完成
- 软硬件解耦验证:国产栈可以承载扩散模型的训练吞吐需求

### 2. 混合架构

自回归与扩散各司其职,再加一个字形专家。

- 自回归主干:9B,负责文本理解与序列建模
- 7B DiT 扩散解码器:负责图像生成
- Glyph Encoder:字形编码器,专攻文字渲染保真
- 指令遵循与画面质量两头兼顾

### 3. 文字渲染:开源第一

汉字结构复杂度高,历来是文生图的最难子问题。

- CVTG-2K Word Accuracy:0.9116
- LongText-Bench 中文:0.979,开源第一,尤擅汉字
- 中文长文本渲染是传统文生图模型的典型短板

### 4. 生成规格与定价

- 分辨率:1024² 至 2048²,任意比例
- API 定价:0.1 元/图
- 模型开源
- 规格区间覆盖社媒配图到高清海报的常见需求

### 5. 产业信号

- 智谱出模型与数据,华为出算力与框架,联合开源
- 为后续国产栈训练更大规模模型提供工程先例
- "国产芯片-国产框架-开源模型"链条首次完整打通

### 6. 文字渲染为什么难

- 汉字笔画密度高、结构嵌套深,细粒度错误率远高于英文
- 长文本还要保持排版一致性与字体连贯性
- Glyph Encoder 专职字形,把"画得对"从扩散主干中剥离出来

### 7. 使用成本测算

- 0.1 元/图的定价支持营销物料的批量生成
- 1024² 至 2048² 覆盖社交媒体到印刷品的分辨率需求
- 开源权重允许本地部署,进一步压低边际成本

## 实践意义

GLM-Image 的示范效应大于单点性能:国产算力首次跑通工业级文生图全流程训练,为"算力自主"提供了可复制模板。工程上,0.979 的中文 LongText-Bench 意味着海报、电商图、课件等中文场景不再需要"生成后 P 字"的后处理;0.1 元/图的定价把高质量中文文生图压到营销物料可批量使用的成本区间。对信创与合规场景,模型开源 + 国产栈训练的组合意味着从训练到推理的完整供应链可控。
