# Anthropic 报告评估 GLM-5.3 网络安全能力:ExploitBench 接近 Mythos Preview,防护绕过率遭点名(Anthropic Report Flags GLM-5.3 Cyber Capabilities)

## 核心观点

9 月 29 日,Anthropic 发布网络安全评估报告,点名智谱 GLM-5.3 已具备较强的进攻性网络安全能力:在 ExploitBench 端到端漏洞利用测试中,GLM-5.3 于 410 次尝试中 50 次完成端到端漏洞利用,与其自家 Claude Mythos Preview(56 次)表现接近;报告还披露研究人员借助 GLM-5.3 发现了浏览器中的未知漏洞,并在隔离环境中完成攻击链验证。

报告同时批评防护:Anthropic 模拟测试中,攻击者用简单技术即可在 64%-100% 的情况下绕过 GLM-5.3 的防护措施,而同类攻击未能对设有防护的 Claude 模型奏效;Anthropic 评估认为"GLM-5.3 松懈的防护措施显著增加了恶意行为者可用的网络能力",同时承认这些能力也让防御者受益。

这是开源权重前沿模型安全边界的一次高关注度第三方评估——GLM-5.3 发布时推迟两周开放权重以完成安全评估与加固,但权重开放后三层"纵深防御"中 API 外侧拦截与推理过程检查不再随权重分发,仅剩模型自身安全对齐生效;报告与智谱"约 100 家安全企业接入"的商业化进展构成同一能力的攻防两面。

## 关键发现 / 关键技术

### 1. ExploitBench:与 Mythos Preview 的差距缩至个位数
- 端到端漏洞利用成功率:GLM-5.3 为 50/410,Claude Mythos Preview 为 56 次,表现接近
- Claude Mythos Preview 是 Anthropic 2026 年 4 月推出的新层级通用前沿 AI 模型,网络安全能力为其强项
- 研究人员借助 GLM-5.3 发现浏览器未知漏洞,并在隔离环境完成攻击链验证——能力达到"可自主构建端到端网络攻击漏洞利用"级别
- Anthropic 特别指出:GLM-5.3 与其他前沿模型的不同之处在于发布时选择开源

### 2. 防护绕过:64%-100% 的批评与"攻防双向"定性
- Anthropic 模拟测试:攻击者通过简单技术可在 64%-100% 的情况下绕过 GLM-5.3 防护;设防的 Claude 模型未被同类攻击绕过
- 报告定性:松懈防护"显著增加了恶意行为者可用的网络能力",但"这些能力也能让致力于保护其系统的防御者受益"
- 对照 GLM-5.3 自身设计:8 月 14 日发布时披露的三层"纵深防御"(API 外侧识别拦截滥用请求、推理过程检查任务意图、模型自身学会拒绝)中,开放权重后仅模型自身安全对齐持续有效
- GLM-5.3 权重已按预告于发布约两周后开放下载(推迟窗口用于安全评估与加固),权重分发使 API 侧防线不再覆盖所有使用场景

### 3. 商业化对照:同一个能力的收入与风险
- 据智谱 9 月 16 日披露,GLM-5.3 发布一个月后网络安全成为率先实现规模化收入的垂直场景,约 100 家安全企业将 GLM 接入产品与业务流程,覆盖国内主要安全厂商、互联网大厂、研究机构和金融机构
- 自 GLM-5.2 起,智谱联合多支安全团队在真实代码库中挖洞,经专家复核、去重后累计发现 2436 个漏洞(1097 个中高危)
- 第三方"竞对评估"成为开源模型安全披露的新形态:能力数据与防护批评同框,评估权在海外厂商手中

## 实践意义

对防御方,报告再次确认前沿模型的漏洞发现/利用能力已达"安全团队工具级"——无论使用闭源还是开源权重模型,都将攻击与防御能力同时放大,接入方需自建使用侧护栏而非依赖模型自带防护。

对开源模型厂商,这份报告给出了"开放权重+安全"的评估范式:能力对标(ExploitBench)与防护鲁棒性(绕过率)将被分别打分;权重开放后模型自身对齐成为唯一随分发走的安全层,后训练阶段的防护强度将直接进入竞争维度。

对行业观察者,这是首次有头部海外厂商以官方报告形式系统评估中国开源前沿模型的网络能力——竞对出具的能力背书与安全批评并存,后续此类"第三方权威评估"可能成为国产模型出海的常态化关卡。
