# RSI 首个工程化实践:Infra Agent 十万卡集群自建推理系统(GLM-5.3 Infra Agent, RSI in Production)

- **原文链接**: [GLM-5.3驱动Infra Agent十万卡集群自建推理系统](https://stcn.com/article/detail/4189153.html)
- **作者**: 证券时报
- **发布日期**: 2026-09-17
- **检索日期**: 2026-09-29
- **标签**: #RSI #InfraAgent #GLM-5.3 #国产芯片 #推理优化 #自进化

## 核心观点

9 月 17 日,智谱披露:由 GLM-5.3 驱动的 Infra Agent 在 10 万+ 张国产芯片集群上从零搭建并调试了一套推理服务系统;不到两周,集群整体处理速度提升至 3 倍,硬件利用效率与单 token 成本已接近主流英伟达 GPU 水平。

该系统并非实验品而是已投产的生产底座:GLM-5.3-Flash(即匿名走红的 Ox-Alpha)6 天内经其处理 62 万亿 token。这是国内首次公开"AI 自我改进"(RSI)用于生产的案例,也是次日发布的 GLM-5.3-FlashX 提速 5 倍的底层支撑,并与 GLM-6"自进化"路线形成工程前奏。

值得注意的是披露的克制口径:改进对象是推理基础设施而非模型权重,收益可即时在线上度量,人类仍掌握系统边界——这为"自我改进"划出了一条可审计的工程化路线。

## 关键发现 / 关键技术

### 1. Infra Agent 做了什么
- 在 10 万+ 张国产芯片集群上从零搭建推理服务,覆盖系统搭建、参数调试与性能调优全流程
- 优化对象是推理服务全栈:调度、通信与算子适配等环节均由 Agent 完成并迭代
- 不到两周,集群整体处理速度提升至 3 倍
- 硬件利用效率与单 token 推理成本接近主流英伟达 GPU 水平——国产芯片相对英伟达生态的"软件效率折扣"被 Agent 大幅收窄

### 2. 已投产:承载 Ox-Alpha 真实流量
- GLM-5.3-Flash 即 OpenRouter / OpenCode 匿名测试走红的 Ox-Alpha,上线 6 天处理 62 万亿 token
- 62 万亿 token 的真实流量构成生产级压力测试,验证 Agent 自建系统在超大规模下的稳定性
- 该推理系统是其背后的生产底座,与中报业绩会披露"端到端服务性能较同硬件初始基线提升 3 倍"互相印证

### 3. RSI 从研究概念到生产工程
- 国内首次公开"AI 自我改进"用于生产:模型优化自身赖以运行的推理基础设施,改进结果直接反哺线上服务
- 与 GLM-6 路线衔接:业绩会提出的"全自训练"(模型参与数据生成、训练环境搭建与基础设施优化)率先在基础设施环节落地
- 匿名测试登顶(Ox-Alpha)、业绩会"3 倍基线"披露与本篇报道三点互证,数据口径一致性较高
- 为 GLM-5.3-FlashX 的 5 倍提速提供底层支撑:先有集群级 3 倍,才有模型服务级 5 倍(见 [GLM-5.3-FlashX 发布](glm-5-3-flashx.md))

## 实践意义

Infra Agent 把 RSI 从论文概念变成生产工程:模型优化自己赖以运行的推理栈,改进直接兑现为线上吞吐(集群 3 倍)与后续产品提速(FlashX 5 倍)。

对基础设施团队,这预示"Agent 自动适配国产芯片"将取代"人力移植 CUDA 生态"成为收窄硬件效率差距的主要路径;国产算力的竞争力短板正在从"芯片制程"转移到"谁的 Agent 更会调系统"。

对行业观察者,国内首次公开的生产级 RSI 说明"AI 改进 AI"已从研究预览进入商业变现环节;风险侧同样值得记录——效率类自我改进的收益可即时度量,但自我改进的边界仍需人类把关与独立审计。

## 跨厂商对比

- 与 [研究加速:OpenAI 内部视角](../../openai/research/research-acceleration-view-inside-openai.md) 对比:OpenAI 披露的是研究流程内部化——中位研究者日日用 agent、每个人类工作日对应 3.1 个 agent-工作日,仍以人类研究者为主导;智谱则让 agent 独立完成基础设施工程并投产,是 RSI 更激进的"去人化"落地
- 与 [自动化研究者能可靠缓解对齐失败](../../anthropic/research/automated-researchers-mitigate-alignment-failures.md) 互补:Anthropic 验证 AI 改进 AI 的对齐侧(Claude 自主修复 10 类对齐失败),智谱 Infra Agent 展示效率侧(自建推理系统),"AI 改进 AI"的两翼同时有了实证
- 与 [智谱 2026 半年度业绩会](zhipu-h1-2026-earnings-glm-6.md) 对比:业绩会上"全自训练"与 GLM-6"自进化"还属路线陈述,Infra Agent 是其首个可验证的工程注脚
- 与 [GLM-5.3](glm-5-3.md) 对比:驱动 Infra Agent 的正是旗舰 GLM-5.3 本身——旗舰模型不再只服务外部客户,也开始承担内部基础设施工程,"模型即员工"率先在运维场景兑现
