# GLM-5.3 接入 Amazon Bedrock:海外云分成收入通道正式开启(GLM-5.3 Available on Amazon Bedrock)

- **原文链接**: [智谱将开启海外"收租" GLM-5.3接入亚马逊云科技等](https://stcn.com/article/detail/4206610.html)

- **检索日期**: 2026-10-16

## 核心观点

10 月 6 日,亚马逊云科技(AWS)旗下大模型服务平台 Amazon Bedrock 官宣接入智谱 GLM-5.3,AWS 基于模型调用量与智谱进行收入分成——9 月中旬 50 亿美元再融资时预告的"海外云托管 API 分成收入 10 月起确认"如期兑现,智谱正式打开海外"收租"通道。

分成模式不止 AWS 一家:除 AWS 外,智谱近期已与多家海外云厂商落地收入分成合作;国内方面,智谱也已与阿里云百炼平台等头部云厂商签署类似分成协议,华为云已上架 GLM-5.3 并就类似合作达成意向。消息当日智谱港股涨逾 7%,叠加前一日 Cursor 接入利好连续走强。

对年末 ARR 30 亿美元指引而言,云分发是 API 直营之外的第二条规模化收入曲线,且云厂商承担推理基础设施——在国产算力供给约束贯穿全年的背景下,这一模式把算力支出转化为分成收入,财务结构意义不亚于收入本身。

## 关键发现 / 关键技术

### 1. 分成模式:按调用量分成,云厂商承担托管
- Amazon Bedrock 官宣接入 GLM-5.3,AWS 基于模型调用量与智谱进行收入分成
- 智谱此前披露:计划通过海外云平台收入分成增加一条具有规模潜力的商业路径,分成收入自 10 月起确认
- 模式本质:云厂商负责托管与推理资源,模型厂商出让部分收入换取全球渠道——海外开发者以 AWS 原生方式调用 GLM-5.3

### 2. 分发网络:海外多家+国内头部云全覆盖
- 海外:除 AWS 外,近期与多家海外云厂商落地收入分成合作模式
- 国内:与阿里云百炼平台等头部云厂商已签署类似分成协议;华为云已上架 GLM-5.3,并就类似合作达成意向
- GLM-5.3 成为同时进入中美头部云厂商模型市场的国产旗舰(发布两个月内完成海外双通道:工具侧 Cursor+云侧 Bedrock)

### 3. 财务与市场反应
- 消息当日(10-06)智谱港股涨逾 7%;前一交易日已因 Cursor 接入涨 4.95%
- 此前披露:全业务 ARR 达 18 亿美元,年末指引由 24 亿上调至 30 亿美元——云分成是指引上调的关键新变量
- 与 9 月"小股大债"再融资(50 亿美元全部投算力扩容)形成闭环:自有算力服务直营需求,云厂商算力服务分成需求

## 实践意义

对海外开发者,GLM-5.3 进入 Bedrock 意味着可在既有 AWS 账号/合规/计费体系内直接调用,采购、安全审查与数据驻留谈判成本大幅降低——这是国产模型真正进入海外企业采购清单的形态。

对模型厂商,云分成把"渠道"外包给云厂商,把自有算力留给最高价值的直营负载,在供给约束下实现收入与算力的解耦;分成比例、模型版本更新节奏与云侧独占性将成为新的商业设计变量。

对行业,MaaS 商业模式出现分岔:直营 API(定价权高、算力自担)与云分发分成(渠道广、算力外包)并行,头部模型厂商的"上架能力"开始像应用的上架运营一样成为独立竞争力。

## 跨厂商对比

- 与 [OpenAI frontier models and Codex are now available on AWS](../../openai/research/openai-frontier-models-and-codex-are-now-available-on-aws.md) 对比:OpenAI 模型上 AWS 是闭源模型的多云分发策略延续,GLM-5.3 上架则是国产开放权重模型首次借海外头部云进入全球企业市场;同为"按用量分成",OpenAI 保卫存量,GLM 开辟增量
- 与 [50 亿美元再融资与 ARR 指引](zhipu-5b-refinancing-arr-guidance.md) 对比:再融资篇预告"海外云托管 API 分成收入 10 月起确认",本文即其兑现记录——从资本开支(算力扩容)到收入分成,一个月内闭环
- 与 [GLM-5.3-Flash](glm-5-3-flash.md) 互补:Ox-Alpha 匿名登顶验证海外开发者需求存在,Bedrock 分成把需求转化为可计费、可合规采购的通道——需求验证与变现通道互为前提
- 与 [DeepSeek API 调价](../../deepseek/news/deepseek-api-price-adjustment-2026-08.md) 对比:DeepSeek 以峰谷分时计费优化自有算力的供需匹配,智谱以云分成把推理负载外包给云厂商——供给约束下国内头部厂商的两种镜像解法
