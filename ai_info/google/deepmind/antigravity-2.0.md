## 核心观点

Google 发布 Antigravity 2.0，定位为 "Agent-first" 开发平台，深度集成 Gemini 3.5 Flash，支持大规模部署协作子代理。这是 Google 对标 OpenAI Codex 和 Anthropic Claude Code 的 Agent 开发平台。

## 关键能力

- **Agent-first 架构**：不是聊天界面，而是为 Agentic 工作流设计的开发平台
- **协作子代理**：支持部署多个并行子代理，大规模处理复杂任务
- **Gemini 3.5 Flash 原生集成**：作为默认推理引擎
- **Science Skills**：30+ 生命科学数据库的原生集成
- **企业级**：与 Gemini Enterprise Agent Platform 打通

## 应用场景

- 自动重命名和分类非结构化资产
- 多步骤工作流自动执行
- 科学计算（结构生物信息学、基因组分析）
- 企业 R&D 加速

## 关键洞察

1. Google 将 Agent 平台作为核心产品战略，而非附加功能
2. Antigravity = Google 版的 Codex/Claude Code，但更强调**多代理协作**和**科学场景**
3. 与 Google Cloud 生态的整合是差异化优势
